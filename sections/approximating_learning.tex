\section{Decision Trees via Covering Problems} \label{sec:AL}


In this section we present approximation algorithms for $\ProblemPCWCDT$ and $\ProblemPCACDT$ by reducing them to $\ProblemPCSC$ and $\ProblemPCMSSC$, respectively. The overarching idea is to use a solution of the appropriate covering problem to find a precedence-closed sequence of tests whose execution makes every remaining hypothesis set significantly smaller than $\spr{\cH}$. Moreover, the cost of performing these tests should be $\bigo\br{\OPT}$ (up to the approximation ratio of the covering problem). The rest of the decision tree is then built recursively and since the depth of the recursion is $\bigo\br{\log n}$ for the constant coverage-loss factors used in our applications, the multiplicative loss in the approximation ratio is $\bigo\br{\log n}$. In what follows we make these ideas precise.

We consider feasible instances, so some test distinguishes each pair of hypotheses. Singleton instances require no tests. All sepcover constructions below concern instances with at least two hypotheses. We will require some additional notation.
%For any node $v$ of the $D$ by $\cH_v$ we will mean the set of hypotheses such that the test $t$ associated with $v$ is performed in $D$ if the set of possible hypotheses is $\cH_v$.
Let $\cH'\subseteq \cH$. By $t\br{\cH'}$ we denote the test $t$ restricted to hypotheses in $\cH'$, i.e., for each reply $H\in t$, we have a reply $H\cap \cH'$ in $t\br{\cH'}$ (if it is nonempty). By $D\setminus V$ we denote the collection of subtrees (a forest) obtained by the removal of all nodes in $V$ from $D$.
We will use the following immediate monotonicity properties. 
\begin{lemma}\label{lemma:subspace_opt}
    Let $\cI=\br{\cH, \cT,\preceq}$ and $\cI'=\br{\cH', \cT, \preceq}$ be two instances of $\ProblemPCACDT$ or $\ProblemPCWCDT$, where $\cH'\subseteq \cH$.
    Then, $\OPT\br{\cI'} \leq \OPT\br{\cI}$.
\end{lemma}
\begin{lemma}\label{lemma:subinstances_avg}
    Let $\cI=(\cH, \cT, \preceq)$ be an instance of $\ProblemPCACDT$.
    Let $\cH_1,\dots,\cH_k\subseteq \cH$ be such that $\bigcup_{i=1}^k \cH_i \subseteq \cH$ and for any $i\neq j$, $\cH_i\cap \cH_j = \emptyset$.
    Then, $\OPT\br{\cI} \geq \sum_{i=1}^k \OPT\br{\br{\cH_i, \cT, \preceq}}$.
\end{lemma}

The following definition gives a basic tool for analysis of our algorithms.
\begin{definition}[Sepcover]
  Let $D$ be any decision tree for $\cI=\br{\cH, \cT, \preceq}$.
  Let $v$ be a test node that is closest to the root and has the property that after removal of the vertices on the root-to-$v$ path from $D$, each remaining subtree has at most $\spr{\cH}/2$ leaves.
  Then the sequence $\tests{D}{v}$ is called a \emph{sepcover} for $D$ and is denoted by $\sepcoverD{D}$.
  If $D$ is optimal for the decision-tree objective under consideration, then we write $\sepcover{\cI} = \sepcoverD{D}$ (ties broken arbitrarily).
\end{definition}

Intuitively, our idea is to construct a set covering instance such that its optimal solution is connected to the cost of tests in the sepcover of an optimal decision tree. This is done as follows.
%We will say that a test in $\sepcover{\cI}$ \emph{sepcovers} an element $u \in \cH$ in $C$ if after applying the test $t$ in $C$, $u$ belongs to a reply $\cH'$ of size at most $\spr{\cH}/2$.
Consider a set of hypotheses $\cH$ and tests $\cT$.
For each test $t\in\cT$, let
\[
\xi(t)=\brc{h\in\cH \mid h\in H \textup{ for some }H\in t\textup{ s.t. }  \spr{H}\leq\frac{3}{4}\cdot\spr{\cH}}.
\]
We regard $\xi\br{\cT}=\brc{\xi(t)\mid t\in\cT}$ as an \emph{indexed family}: distinct tests give distinct sets even when their contents coincide. If $\preceq$ is a partial order on $\cT$, then $\preceq_{\xi}$ is the corresponding partial order on $\xi(\cT)$, i.e., $t\preceq t'$ if and only if $\xi(t)\preceq_{\xi}\xi(t')$.
By extension, for any subset $S\subseteq\cT$, $\xi(S)=\brc{\xi(t) \mid t\in S}$. For a sequence $S$, the map $\xi$ preserves its order.
We also set $\cU_{\xi}=\bigcup_{t\in\cT}\xi(t)$.
For a family or sequence $\cC$ of indexed sets, $\xi^{-1}(\cC)$ is the corresponding family or sequence of tests.
\begin{lemma}
    If $\spr{\cH}\geq2$, then $\spr{\cU_{\xi}}\geq \spr{\cH}-1$ and $\spr{\cU_{\xi}}\geq \frac{4}{5}\cdot\spr{\cH}$.
\end{lemma}
\begin{proof}
    If $\spr{\cH}\leq4$, then there exists a test $t$ which separates some pair of hypotheses and thus for every $H\in t$, $\spr{H}\leq\frac{3}{4}\cdot\spr{\cH}$, and therefore $\xi\br{t}=\cH$. Assume that $\spr{\cH}\geq5$. We show that there is at most one hypothesis that is not in $\cU_{\xi}$. To see this observe that if a hypothesis $h_1\notin \cU_{\xi}$, then for every test $t\in\cT$, it holds that for the reply $H\in t$ containing $h_1$, $\spr{H}>\frac{3}{4}\cdot\spr{\cH}$. Assume that there is a second hypothesis $h_2\notin \cU_{\xi}$. By definition we know that there exists a test which distinguishes $h_1$ and $h_2$, so $h_2$ needs to belong to a reply of size at most $\frac{3}{4}\cdot\spr{\cH}$, a contradiction. Thus $\spr{\cU_{\xi}}\geq \min_{i\geq5}\brc{\frac{i-1}{i}}\cdot\spr{\cH}=\frac{4}{5}\cdot\spr{\cH}$.
\end{proof}
 
%In our construction, in order to solve a $\ProblemPCDT$ for an instance $\cI=\br{\cH, \cT, \preceq}$, we will apply an algorithm for $\ProblemPCSC$ with an input $\cI=\br{\cH, \xi(\cT), \preceq_{\xi}, \spr{\cH}/4}$.

The idea behind the algorithms for the $\ProblemPCWCDT$ (Section~\ref{subsection:PCWCDT}) and the $\ProblemPCACDT$ (Section~\ref{subsection:PCACDT}) is similar.
Hence we extract here the common generic subroutine (see Algorithm~\ref{alg:worstDecisionTree}).
The only difference is a black-box procedure (we call it $\blackBox$) that is used to solve a particular subproblem - either $\ProblemPCSC$ or $\ProblemPCMSSC$, respectively.
Let $\cC$ be the set cover obtained for the instance $\br{\cU_{\xi}, \xi\br{\cT}, \preceq_{\xi}, f=1/4}$ by the black-box procedure.
If $\cC$ is returned as a family by an approximation algorithm for $\ProblemPCSC$, order it topologically. In either case, retain only the shortest prefix covering at least $\spr{\cU_{\xi}}/(4\cdot\beta)$ hypotheses. This preserves precedence closure and does not increase either objective.
% Note that $\cC$ is supposed to play the role of $\sepcover{\cI}$ according to the lower bounds in Lemmas~\ref{lemma:cover_sep_worst_case} and~\ref{lemma:cover_sep_average_case} given in the subsections below.
We iteratively build a decision tree $D$ by appending tests associated with consecutive sets from $\cC$.
During each such iteration, we look at all possible replies to the appended test and for each sufficiently small reply $\cH'$ ($\spr{\cH'} \leq \frac{5\cdot\beta-1}{5\cdot\beta}\cdot \spr{\cH}$), we recursively call \ProcDecisionTree on the subinstance induced by $\cH'$. If there exists a large reply $\cH'$ ($\spr{\cH'} > \frac{5\cdot\beta-1}{5\cdot\beta}\cdot \spr{\cH}$), then we continue appending tests from $\cC$ as a reply associated with $\cH'$. Note that since $\frac{5\cdot\beta-1}{5\cdot\beta}>\frac{1}{2}$ for any $\beta \geq 1$, there is at most one such reply.
% We also note that the sequence of tests $t_1,t_2\ldots$ in Algorithm~\ref{alg:worstDecisionTree} is a `substitute' of sepcover (cf. Lemma~\ref{lemma:cover_sep_worst_case}).
Every hypothesis covered by $\cC$ leaves the current path by its covering test, unless the path has already ended. Since $\spr{\cov\br{\cC}}\geq\spr{\cU_{\xi}}/(4\cdot\beta)\geq\spr{\cH}/(5\cdot\beta)$, no reply after the last test exceeds the recursion threshold, so the procedure returns within the loop. Recursive calls may repeat an earlier test. Its reply is already determined, so these repetitions can be deleted afterward without increasing cost or violating precedence. The immediate recursive calls partition the current hypotheses into at least two nonempty subsets, and each path segment contains at most $m$ tests. Thus there are $\bigo(n)$ calls and the explicit tree has $\bigo(n(m+1))$ nodes.

\subsection{Precedence Constrained Worst Case Decision Tree} \label{subsection:PCWCDT}

We have the following immediate corollary of the definition of sepcover.
\begin{observation} \label{obs:sepcoverWC}
    Let $\cI$ be any instance of $\ProblemPCWCDT$.
    Then, $\spr{\sepcover{\cI}} \leq \OPT\br{\cI}$.
\end{observation}

%We will use $\spr{\sepcover{\cI}}$ as a lower bound on $\OPT\br{\cI}$ in the analysis of the approximation algorithm for $\ProblemPCWCDT$.
\begin{lemma}\label{lemma:cover_sep_worst_case}
    Let $\cI=\br{\cH, \cT, \preceq}$ be any $\ProblemPCWCDT$ instance.
    Let $\cC^*$ be an optimal solution to $\ProblemPCSC$ on instance $\br{\cU_{\xi}, \xi(\cT), \preceq_{\xi}, f=1/4}$.
    %and a test $t$ covers $h\in \cH$ if $\brc{U_{t}\br{u}}\leq \frac{3}{4}\cdot \brc{\mathcal{U}}$.
    Then, $\spr{\cC^*} \leq \spr{\sepcover{\cI}}$.
\end{lemma}
\begin{proof}
    Write $S=\angl{t_1,\ldots,t_\ell}=\sepcover{\cI}$ in path order and put $n=\spr{\cH}$. Before the first prefix of $\xi(S)$ covers at least $\spr{\cU_{\xi}}/4$ hypotheses, we claim that every hypothesis that has left the path is already covered. This holds before $t_1$. Suppose it holds before $t_i$, and let $\cH_i$ be the hypotheses still on the path. For any reply $H\in t_i$ that leaves the path, the sepcover property gives $\spr{H\cap\cH_i}\leq n/2$. The induction hypothesis gives
    \[
    \spr{H}=\spr{H\cap\cH_i}+\spr{H\setminus\cH_i}
    \leq \frac n2+\spr{\cH\setminus\cH_i}
    <\frac n2+\frac{\spr{\cU_{\xi}}}{4}\leq\frac{3\cdot n}{4}.
    \]
    Thus $H\subseteq\xi(t_i)$, proving the claim. At $t_\ell$, all replies leave the path, so some prefix must reach the target. This prefix is precedence-closed and has at most $\spr{S}$ sets, proving the lemma.
\end{proof}

For a sequence $S$ of tests along a specified path from the root of $D$, denote its path of test nodes by $D_S$, with $\COSTW\br{D_S}=\spr{S}$. For the cover $\cC$ returned by $\blackBox$, we write $D_{\cC}$ for the path built during the current call to Algorithm~\ref{alg:worstDecisionTree}. Its tests form a prefix of $\xi^{-1}(\cC)$.
The following observation is due to Lemmas \ref{lemma:subspace_opt} and \ref{lemma:cover_sep_worst_case}:
    \begin{observation} \label{obs:DS}
        Consider $D_{\cC}$ computed in Algorithm~\ref{alg:worstDecisionTree}, that uses a $\br{\alpha,\beta}$-approximation algorithm for $\ProblemPCSC$ as the $\blackBox$ subroutine.
        %Let $D_S$ be the decision tree built on tests from $S$ respecting the precedence constraints $\preceq$.
        Then, $\COSTW\br{D_{\cC}} \leq \alpha \cdot \spr{\sepcover{\cI}}$.
    \end{observation}


\begin{theorem} \label{thm:PCSC-to-PCWCDT}
If there is a polynomial-time bicriteria $\br{\alpha, \beta}$-approximation algorithm for $\ProblemPCSC$, then there is a polynomial-time
$\bigo\br{\frac{\alpha}{\log\br{\frac{5\cdot\beta}{5\cdot\beta -1}}} \cdot \log n}$-approximation algorithm for $\ProblemPCWCDT$.
% In particular when $\gamma = \bigo\br{1}$, the approximation is $\bigo\br{\alpha \cdot \log n}$.
\end{theorem}
\begin{proof}
     \setlength{\emergencystretch}{2em}
     Run \ProcDecisionTree on $\cI=\br{\cH,\cT,\preceq}$ using a $\br{\alpha,\beta}$-approximation for $\ProblemPCSC$ as $\blackBox$.
     We prove by induction on $n=\spr{\cH}$ that
     \begin{equation} \label{eq:D}
     \COSTW\br{D} \leq \frac{\alpha}{\log\br{\frac{5\cdot\beta}{5\cdot\beta -1}}}\cdot \log n \cdot \OPT\br{\cI}.
     \end{equation}

     Put $\rho=(5\cdot\beta-1)/(5\cdot\beta)$ and $a=\alpha/\log(1/\rho)$. The base case $n=1$ has cost zero. Assume that every recursive call on $\cI'=\br{\cH',\cT,\preceq}$ returns $D'$ with $\COSTW\br{D'}\leq a\cdot\log\spr{\cH'}\cdot\OPT\br{\cI'}$. Let $\cF=D\setminus V\br{D_{\cC}}$ be the forest of recursive subtrees. Then
        \begin{align*}
            &\COSTW\br{D} \leq \COSTW\br{D_{\cC}}+\max_{D'\in\cF}\COSTW\br{D'} \\
            &\leq \alpha\cdot\spr{\sepcover{\cI}}+\max_{D'\in\cF}\brc{a\cdot\log\spr{\cH'}\cdot\OPT\br{\cI'}}
            \leq \alpha\cdot\OPT\br{\cI}+a\cdot\log(\rho\cdot n)\cdot\OPT\br{\cI} \\
            &=\alpha\cdot\OPT\br{\cI}+a\cdot\log n\cdot\OPT\br{\cI}-\alpha\cdot\OPT\br{\cI}
            =a\cdot\log n\cdot\OPT\br{\cI}.
        \end{align*}
        The second inequality uses the induction hypothesis and Observation~\ref{obs:DS}. The third uses Observation~\ref{obs:sepcoverWC}, Lemma~\ref{lemma:subspace_opt}, and $\spr{\cH'}\leq\br{1-\frac45\cdot\frac{1}{4\cdot\beta}}\cdot n=\rho\cdot n$ for every $D'\in\cF$. Finally, $a\cdot\log\rho=-\alpha$, proving~\eqref{eq:D}.
\end{proof}

Theorem~\ref{thm:PCSC-to-PCWCDT} and the covering algorithms in Section~\ref{sec:SC} give the following corollary:
\begin{corollary}\label{cor:PCWCDT-special-cases}
    There exist polynomial-time algorithms for $\ProblemPCWCDT$ with the following guarantees:
    \begin{itemize}
        \item $\bigo\br{\log n}$-approximation for inforests, by Theorem~\ref{thm:BPCSC-inforest}, and Corollary~\ref{cor:BPCSC-to-PCSC}.
        \item $\bigo\br{\log m\cdot\log n}$-approximation for outforests, by Theorem~\ref{thm:BPCSC-outforest}.
        \item $\bigo\br{m^{1/3}\cdot\log n}$-approximation for general precedence constraints, by Corollary~\ref{cor:bicriteria-decision-trees}.
    \end{itemize}
\end{corollary}



\subsection{Precedence Constrained Average Case Decision Tree} \label{subsection:PCACDT}

For the average-case objective, bounding the number of tests in a sepcover is insufficient: each test contributes the number of hypotheses that reach it. We therefore compare the total contribution of the selected tests with the corresponding contribution of an optimal sepcover.
We begin with a counting identity.
\begin{observation} \label{obs:dec-tree-averaging}
    If $D$ is a decision tree for $\ProblemPCACDT$, then $\COSTA\br{D}=\sum_{v\in X}\spr{\cH_v}$, where $X$ is the set of all non-leaf vertices of $D$.
\end{observation}
For a subgraph $D'$ of $D$, define $\COSTA\br{D'}=\sum_{v\in V(D')\cap\inner{D}}\spr{\cH_v(D)}$, where $\inner{D}$ is the set of test nodes of $D$. In particular, the last test of a path is counted even though it is a leaf of the path.
Observation~\ref{obs:dec-tree-averaging} allows us to decompose the cost criterion as follows.
\begin{observation} \label{obs:WCdecomposition}
    Let $D$ be any decision tree for an instance of $\ProblemPCACDT$ and let $S=\tests{D}{v}$ for any test node $v$ of $D$, with $D_S$ denoting the path to that node.
    Then,
    \[
    \COSTA\br{D} = \COSTA\br{D_{S}} + \sum_{D'\in D\setminus V\br{D_{S}}} \COSTA\br{D'}.
    \]
%     $$
%     \COSTA\br{D, \cI} = \COSTA\br{S, \cI} + \sum_{D'\in D\setminus S} \COSTA\br{D', \cI}.
%     $$

\end{observation}

    Then, $\coverageTime\br{\cC^*} \leq \COSTA\br{\sepcover{\cI}}$.

\begin{proof}
    Let $\sigma$ be the shortest prefix of $\xi(\sepcover{\cI})$ that covers at least $\spr{\cU_{\xi}}/4$ hypotheses. By the proof of Lemma~\ref{lemma:cover_sep_worst_case}, this prefix exists and is precedence-closed. For $h\in\cU_{\xi}$, let $d(h)$ be the number of tests on the sepcover path performed when the target is $h$. If $h$ leaves the path by the end of $\sigma$, the same proof shows that $h$ is covered no later than its departure, so $\coverageTime\br{h,\sigma}\leq d(h)$. Otherwise, $\coverageTime\br{h,\sigma}\leq\spr{\sigma}\leq d(h)$. Summing gives
    \[
    \coverageTime\br{\cC^*}\leq\coverageTime\br{\sigma}
    =\sum_{h\in\cU_{\xi}}\coverageTime\br{h,\sigma}
    \leq\sum_{h\in\cU_{\xi}}d(h)
    \leq\COSTA\br{\sepcover{\cI}}.\qedhere
    \]
\end{proof}

The following is analogous to Observation~\ref{obs:DS} however requires a more careful consideration.
\begin{observation} \label{obs:DS-average}
    Consider $D_{\cC}$ computed in Algorithm~\ref{alg:worstDecisionTree}, that uses an $\br{\alpha,\beta}$-approximation algorithm for $\ProblemPCMSSC$ as the $\blackBox$ subroutine.
    Then, $\COSTA\br{D_{\cC}} \leq 2\cdot\alpha \cdot \COSTA\br{\sepcover{\cI}}$, where $\cI=\br{\cH,\cT,\preceq}$ is the input instance to $\ProblemPCACDT$.
\end{observation}
\begin{proof}
    If $h\in\cU_{\xi}$ is first covered by $\cC$ at position $j$, then $h$ belongs to a reply of $t_j$ of size at most $3\cdot\spr{\cH}/4\leq (5\cdot\beta-1)\cdot\spr{\cH}/(5\cdot\beta)$. Thus $h$ leaves the current path by test $t_j$, unless the path has already ended. Its contribution to $\COSTA\br{D_{\cC}}$ is at most $j=\coverageTime\br{h,\cC}$. If $h$ is not covered, its contribution is at most $\spr{\cC}=\coverageTime\br{h,\cC}$.
    There is at most one hypothesis in $\cH\setminus\cU_{\xi}$, and its contribution to $\COSTA\br{D_{\cC}}$ is at most $\spr{\cC}$. Since $\cC$ was truncated at the first prefix attaining the required coverage, its last set covers a new hypothesis, so $\spr{\cC}\leq\coverageTime\br{\cC}$.
    Hence, we get that 
    \[
    \COSTA\br{D_{\cC}} \leq \coverageTime\br{\cC} + \spr{\cC} \leq 2\cdot \coverageTime\br{\cC}\leq 
    2\cdot\alpha \cdot \COSTA\br{\sepcover{\cI}}. \qedhere
    \]
\end{proof}

\begin{theorem}\label{thm:PCMSSC-to-PCACDT}
    \setlength{\emergencystretch}{2em}
    If there is a polynomial-time bicriteria $\br{\alpha, \beta}$-approximation algorithm for $\ProblemPCMSSC$, then there is a polynomial-time $\bigo\br{\frac{\alpha}{\log\br{\frac{5\cdot\beta}{5\cdot\beta -1}}}\cdot \log n}$-approximation algorithm for $\ProblemPCACDT$.
    % In particular when $\mu = \bigo\br{1}$, the ratio is $\bigo\br{\beta \cdot \log \br{m+n}}$.
\end{theorem}
\begin{proof}
    \setlength{\emergencystretch}{2em}
    Run \ProcDecisionTree on $\cI=\br{\cH,\cT,\preceq}$ using a $\br{\alpha,\beta}$-approximation for $\ProblemPCMSSC$ as $\blackBox$.
    We argue by induction on $n$ that
    \begin{equation} \label{eq:D-average}
     \COSTA\br{D} \leq \frac{2\cdot\alpha}{\log\br{\frac{5\cdot\beta}{5\cdot\beta -1}}}\cdot \log n \cdot \OPT\br{\cI},
    \end{equation}
    where $D$ is the decision tree returned by Algorithm \ref{alg:worstDecisionTree}.

    Put $\rho=(5\cdot\beta-1)/(5\cdot\beta)$ and $a=2\cdot\alpha/\log(1/\rho)$. The base case $n=1$ has cost zero. Assume that every recursive call on $\cI'=\br{\cH',\cT,\preceq}$ returns $D'$ with $\COSTA\br{D'}\leq a\cdot\log\spr{\cH'}\cdot\OPT\br{\cI'}$. Let $\cF=D\setminus V\br{D_{\cC}}$ be the forest of recursive subtrees. Then
\begin{align*}
    &\COSTA\br{D} =\COSTA\br{D_{\cC}}+\sum_{D'\in\cF}\COSTA\br{D'} \\
    &\leq 2\cdot\alpha\cdot\COSTA\br{\sepcover{\cI}}+\sum_{D'\in\cF}a\cdot\log\spr{\cH'}\cdot\OPT\br{\cI'}
    \leq 2\cdot\alpha\cdot\OPT\br{\cI}+a\cdot\log(\rho\cdot n)\cdot\OPT\br{\cI} \\
    &=2\cdot\alpha\cdot\OPT\br{\cI}+a\cdot\log n\cdot\OPT\br{\cI}-2\cdot\alpha\cdot\OPT\br{\cI}
    =a\cdot\log n\cdot\OPT\br{\cI}.
\end{align*}
The equality uses Observation~\ref{obs:WCdecomposition}. The first inequality uses the induction hypothesis and Observation~\ref{obs:DS-average}. For the second inequality, use Observation~\ref{obs:sepcoverAC}, $\spr{\cH'}\leq\br{1-\frac45\cdot\frac{1}{4\cdot\beta}}\cdot n=\rho\cdot n$, and Lemma~\ref{lemma:subinstances_avg}, since the hypothesis sets of the recursive calls are disjoint. Finally, $a\cdot\log\rho=-2\cdot\alpha$, proving~\eqref{eq:D-average}.
\end{proof}

Thus, by Theorem \ref{thm:PCMSSC-to-PCACDT} we obtain the following corollary:

\begin{corollary}\label{cor:PCACDT-special-cases}
    There exist poly-time algorithms for $\ProblemPCACDT$ with the following guarantees:
    \begin{itemize}
        \item $\bigo\br{\log n}$-approximation for inforests, by Corollary~\ref{cor:BPCSC-inforest-to-PCMSSC}.
        \item $\bigo\br{\log m\cdot\log n}$-approximation for outforests, by Theorem~\ref{thm:BPCSC-outforest}.
        \item $\bigo\br{m^{1/3}\cdot\log n}$-approximation for general precedence constraints, by Corollary~\ref{cor:bicriteria-decision-trees}.
    \end{itemize}
\end{corollary}
