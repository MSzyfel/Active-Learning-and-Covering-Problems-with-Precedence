\section{Set covering with precedence constraints} \label{sec:SC}

% Similarly as in previous section we assume our input instance to be unweighted. Note that the analysis of the following procedures works also in the weighted setting, where every element $u\in\cU$ has a weight $w(u)$ and the goal is to maximize the total weight of covered elements or cover at least a given total weight of elements with minimal size of the cover. Since this generalization is straightforward we omit it for clarity.

We first give a bicriteria algorithm for \textsc{Partial Red-Blue Set Cover}, and transfer its guarantee to $\ProblemPCSC$ and its budgeted version, $\ProblemBPCSC$. We then use the budgeted algorithm to approximate $\ProblemPCMSSC$. For inforests and outforests, reductions to budgeted \textsc{Maximum Coverage} and \textsc{Group Steiner Orienteering}, respectively, yield stronger guarantees.

\begin{problem}[\textsc{Budgeted Precedence Constrained Set Cover} ($\ProblemBPCSC$)] \label{problem:BPCSC}
Given a universe $\cU$ of items, a family $\cS$ of subsets of $\cU$, a precedence relation $(\cS,\preceq)$ and a budget $\budget>0$, find a precedence-closed set $\cC\subseteq\cS$ that maximises $\spr{\cov\br{\cC,\cU}}$ and satisfies $\spr{\cC}\leq \budget$.
\end{problem}
\begin{problem}[\textsc{Partial Red-Blue Set Cover} ($\ProblemPRBSC$)] \label{problem:PRBSC}
Given disjoint sets $\cR$ of red elements and $\cB$ of blue elements, a family $\cA$ of subsets of $\cR\cup\cB$, and an integer target $k$, choose a subfamily $\cA'\subseteq\cA$ that covers at least $k$ blue elements and minimizes \DDfix{the \emph{red cost}} $\spr{\cov\br{\cA',\cR}}$.
\end{problem}

\subsection{A bicriteria algorithm for Partial Red-Blue Set Cover}
\label{subsection:PRBSC-bicriteria}
Let $m$ be the number of input sets, $n=\spr{\cB}$ the number of blue elements, and $k$ the target number to cover. Chlamt{\'{a}}{\v{c}}, Makarychev and Vakilian give a $\widetilde{\bigo}\br{m^{1/3}}$-approximation for $\ProblemPRBSC$ that covers at least $k$ blue elements~\cite[Section~3 and Appendix~A]{RedBlueSetCover}. Here $\widetilde{\bigo}$ suppresses polylogarithmic factors. We first show that allowing a constant loss in blue coverage removes these factors from the red cost. Our deterministic algorithm covers at least one eighth of the target at cost $\bigo\br{m^{1/3}}$ times the optimum for target $k$. For $n\geq2$, repetition then meets the target at cost $\bigo\br{m^{1/3}\cdot\log n}$ times the optimum.

Our rounding builds on their red-pivot LP rounding and heavy/light cost analysis. They select a useful red pivot and size class and repeat a density-improvement step. We use one strengthened relaxation and round all pivot--size groups together. The pair constraints allow us to sum the heavy-set charges over all size scales, while the assignment-load constraints control the blue coverage of each group. For our bicriteria goal, this avoids their decomposition and repeated pivot and size-class selection, although the global relaxation and coverage analysis require additional arguments. Their Section~3 also uses conditional expectations, whereas our potential handles a fixed coverage target and red cost simultaneously.

\begin{theorem}\label{thm:partial-red-blue-bicriteria}
For instances of $\ProblemPRBSC$ with $m\geq1$ sets and feasible target $k\geq1$, there is a deterministic polynomial-time algorithm covering at least $k/8$ blue elements at a red cost at most $1400\cdot m^{1/3}$ times the optimum for target $k$.
\end{theorem}
\begin{proof}
Write $\cR_A=A\cap\cR$ and $\cB_A=A\cap\cB$ for each $A\in\cA$. First select all sets $A$ with $\cR_A=\emptyset$, that is, all sets containing no red elements. If they cover at least $k/8$ blue elements, return this family. In particular, this handles every instance whose optimum red cost is zero. Otherwise, try each integer guess $K\in[\spr{\cR}]$ for the optimum red cost.

We describe the variables of our relaxation through their intended values in an integral solution. For each red element $r\in\cR$, the variable $y_r\in[0,1]$ indicates whether $r$ is covered. For each set $A\in\cA$, the variable $x_A\in[0,1]$ indicates whether $A$ is selected. For each blue element $u\in\cB$, the variable $z_u\in[0,1]$ indicates whether $u$ is one of the $k$ covered blue elements chosen to meet the target. A selected set may cover additional blue elements with $z_u=0$.

For each incidence $u\in \cB_A$, the nonnegative variable $a_{u,A}$ indicates that the chosen blue element $u$ is assigned to the selected set $A$. Each chosen blue element is assigned to one selected set containing it. In a fractional solution, $a_{u,A}$ is the part of $z_u$ assigned to $A$. Finally, for each ordered pair $r,t\in\cR$, the nonnegative variable $y_{r,t}$ represents the joint coverage of the two red elements. Its intended integral value is $y_r\cdot y_t$. We do not impose this nonlinear equality, but use linear inequalities that it satisfies.

For the current guess $K$, find a feasible solution to
\begin{align}
 \sum_{r\in\cR}y_r&\leq K,& \sum_{u\in\cB}z_u&=k, \label{eq:rbsc-lp-budget}\\
 \sum_{A:u\in \cB_A}a_{u,A}&=z_u &&(u\in\cB), \label{eq:rbsc-lp-assign}\\
 a_{u,A}&\leq x_A &&(A\in\cA,\ u\in \cB_A), \label{eq:rbsc-lp-marginal}\\
 \sum_{u\in \cB_A}a_{u,A}&\leq k\cdot x_A &&(A\in\cA), \label{eq:rbsc-lp-set}\\
 x_A&\leq y_r &&(A\in\cA,\ r\in \cR_A), \label{eq:rbsc-lp-red}\\
 \sum_{A:r\in \cR_A,\,u\in \cB_A}a_{u,A}&\leq y_r &&(r\in\cR,\ u\in\cB), \label{eq:rbsc-lp-blue-load}\\
 \sum_{A:r\in \cR_A}\sum_{u\in \cB_A}a_{u,A}&\leq k\cdot y_r &&(r\in\cR), \label{eq:rbsc-lp-total-load}\\
 x_A&\leq y_{r,t} &&(A\in\cA,\ r,t\in \cR_A), \label{eq:rbsc-lp-pair}\\
 \sum_{t\in\cR}y_{r,t}&\leq K\cdot y_r &&(r\in\cR). \label{eq:rbsc-lp-pair-budget}
\end{align}
The assignment constraints limit the load on each set and red element. In particular, they prevent the same blue element from contributing too much within a group and bound the total number of marks expected in an active group. The pair constraints give a budget for jointly covered red elements. This will let us charge heavy occurrences across all scales. The following claim verifies the relaxation.

\begin{claim}\label{claim:rbsc-lp-validity}
The above system is a polynomial-size relaxation of the existence of a solution covering at least $k$ blue elements at red cost at most $K$.
\end{claim}
\begin{proof}
Let $\cA^*\subseteq\cA$ be such a solution. Choose $k$ blue elements covered by $\cA^*$ and assign each of them to one set of $\cA^*$ containing it. Set $x_A=1$ for $A\in\cA^*$, set $y_r=1$ for red elements covered by $\cA^*$, and set $z_u=1$ for the chosen blue elements. Set $a_{u,A}=1$ precisely for the chosen assignments and set all other variables of these four types to zero. Finally, set $y_{r,t}=y_r\cdot y_t$.

The budget and assignment constraints hold by construction. Each assigned blue element belongs to a selected set, and at most $k$ blue elements are assigned to any set, proving~\eqref{eq:rbsc-lp-marginal} and~\eqref{eq:rbsc-lp-set}. A selected set contains only covered red elements, proving~\eqref{eq:rbsc-lp-red} and~\eqref{eq:rbsc-lp-pair}. If $y_r=0$, no selected set contains $r$, so both assignment sums involving $r$ vanish. If $y_r=1$, a fixed blue element is assigned at most once, and there are $k$ assignments in total. This proves~\eqref{eq:rbsc-lp-blue-load} and~\eqref{eq:rbsc-lp-total-load}. Moreover,
\[
 \sum_{t\in\cR}y_{r,t}=y_r\cdot\sum_{t\in\cR}y_t\leq K\cdot y_r,
\]
which proves~\eqref{eq:rbsc-lp-pair-budget}. The numbers of variables and constraints are polynomial in the explicit input size. In particular, the guess $K=\OPT$ gives a feasible relaxation.
\end{proof}

Skip every guess with an infeasible relaxation. For a feasible guess, fix a feasible solution and put
\[
 T=m^{1/3},\qquad \cR_+=\brc{r\in\cR:y_r\geq1/T},\qquad \cR'_A=\cR_A\setminus \cR_+.
\]
We call $\cR'_A$ the \emph{residual red part} of $A$. By~\eqref{eq:rbsc-lp-budget}, $\spr{\cR_+}/T\leq\sum_{r\in \cR_+}y_r\leq K$, so $\spr{\cR_+}\leq K\cdot T$. Initially select every set with $\cR'_A=\emptyset$. These sets cover only red elements in $\cR_+$. If they cover at least $k/8$ blue elements, retain them as the candidate for this guess. Otherwise, let $\cB'$ be the blue elements not covered by these sets. The number of initially covered blue elements is strictly smaller than $k/8$. Since $z_u\leq1$, we obtain
\begin{equation}\label{eq:rbsc-residual-mass}
 \sum_{u\in\cB'}z_u
 =k-\sum_{u\in\cB\setminus\cB'}z_u
 \geq k-\spr{\cB\setminus\cB'}>7\cdot k/8.
\end{equation}

For every power of two $s=2^j\leq\spr{\cR}$ with $j\in\mathbb{Z}_{\geq0}$, which we call a \emph{scale}, define $\cA_s$ and, for each $r\in\cR\setminus \cR_+$ with $y_r>0$, the \emph{group} $\cA_{r,s}$ by
\[
 \cA_s=\brc{A\in\cA:s\leq\spr{\cR'_A}<2\cdot s},
 \qquad
 \cA_{r,s}=\brc{A\in\cA_s:r\in \cR'_A}.
\]
Each set with a nonempty residual red part belongs to one $\cA_s$. We call $r$ the \emph{pivot} of $\cA_{r,s}$. A set $A\in\cA_s$ belongs to the group $\cA_{r,s}$ for each residual red element $r\in\cR'_A$ with $y_r>0$. We call its membership in each such group an \emph{occurrence} of $A$. A set at scale $s$ has at least $s$ residual red elements and hence, unless its LP value is zero, at least $s$ occurrences. This multiplicity will compensate for the factor $1/s$ in the activation probability.

For each pivot $r$ and scale $s$, let $E_{r,s}$ be the event that group $\cA_{r,s}$ is activated, with $\Pr[E_{r,s}]=y_r/s$. For each $A\in\cA_{r,s}$, let $J_{r,s,A}$ be the event that its trial succeeds, with $\Pr[J_{r,s,A}]=x_A/y_r$. The activation and trial events are mutually independent, including across groups with the same members. An occurrence of $A$ is selected if and only if both $E_{r,s}$ and $J_{r,s,A}$ occur, so selection events in the same group share the activation event. Both probabilities belong to $[0,1]$ by~\eqref{eq:rbsc-lp-red} and $s\geq1$. Let $\cF_{r,s}\subseteq\cA_{r,s}$ be the random family of sets whose occurrences in group $\cA_{r,s}$ are selected. The output consists of the initially selected sets and every original set with at least one selected occurrence.

Define the random sets $\cR_{r,s}$ and $\cR_0$, and the random variable $R$, by
\[
 \cR_{r,s}=\bigcup_{A\in\cF_{r,s}}\cR'_A,
 \qquad \cR_0=\bigcup_{r,s}\cR_{r,s},
 \qquad R=\spr{\cR_+}+\spr{\cR_0}.
\]
The output's actual red cost is at most $R$, because its covered red elements outside $\cR_0$ all belong to $\cR_+$.

\begin{claim}\label{claim:rbsc-red-cost}
The random construction satisfies $\mathbb{E}[R]\leq7\cdot K\cdot T$.
\end{claim}
\begin{proof}
Put $\theta=K/T$. We split occurrences according to their trial probabilities: heavy occurrences can be charged to the joint red variables, while light occurrences are cheap enough to count individually. For each group $\cA_{r,s}$, partition its occurrences into the \emph{heavy} and \emph{light} families
\[
 \cA^h_{r,s}=\brc{A\in\cA_{r,s}:x_A/y_r\geq\theta/s},
 \qquad \cA^\ell_{r,s}=\cA_{r,s}\setminus\cA^h_{r,s}.
\]
The same set may be heavy in one group and light in another. Define the random sets of residual red elements reached by selected heavy and light occurrences by
\[
 \cR_h=\bigcup_{r,s}\bigcup_{A\in\cF_{r,s}\cap\cA^h_{r,s}}\cR'_A,
 \qquad
 \cR_\ell=\bigcup_{r,s}\bigcup_{A\in\cF_{r,s}\cap\cA^\ell_{r,s}}\cR'_A.
\]
Define $R_h=\spr{\cR_h}$ and $R_\ell=\spr{\cR_\ell}$. Since every selected occurrence is either heavy or light, $R\leq\spr{\cR_+}+R_h+R_\ell$. We bound the expectations of these two variables separately.

Fix residual red elements $r,t$ with $y_r>0$, and let $F_{r,t}$ be the event that a selected heavy occurrence in some group $\cA_{r,s}$ contains $t$. For all other ordered red pairs, let $F_{r,t}$ be the empty event. Let $\cS_{r,t}$ be the set of scales $s$ for which group $\cA_{r,s}$ contains a heavy occurrence of a set $A$ with $t\in\cR'_A$. A selected occurrence requires its group to be active, and hence
\[
 F_{r,t}\subseteq\bigcup_{s\in\cS_{r,t}}E_{r,s},
 \qquad
 \Pr[F_{r,t}]\leq\sum_{s\in\cS_{r,t}}\frac{y_r}{s},
\]
where the probability bound is the union bound. If $\cS_{r,t}$ is empty, the event $F_{r,t}$ is impossible. Otherwise, for each $s\in\cS_{r,t}$, a corresponding heavy occurrence satisfies
\[
 y_{r,t}\geq x_A\geq\frac{\theta\cdot y_r}{s},
\]
where the first inequality follows from~\eqref{eq:rbsc-lp-pair}. In particular, $y_{r,t}>0$ and $s\geq\theta\cdot y_r/y_{r,t}$. Let $s_0$ be the smallest scale in $\cS_{r,t}$. All scales are powers of two, so every scale in $\cS_{r,t}$ is of the form $2^j\cdot s_0$ for some integer $j\geq0$. Using the geometric series $\sum_{j\geq0}2^{-j}=2$ gives
\[
 \Pr[F_{r,t}]\leq\sum_{s\in\cS_{r,t}}\frac{y_r}{s}
 \leq\sum_{j\geq0}\frac{y_r}{2^j\cdot s_0}=\frac{2\cdot y_r}{s_0}
 \leq\frac{2\cdot y_{r,t}}{\theta}.
\]
The same bound holds when $\cS_{r,t}$ is empty, since $y_{r,t}\geq0$. If $t\in\cR_h$, then some selected heavy occurrence containing $t$ belongs to a group $\cA_{r,s}$, so $F_{r,t}$ occurs for its pivot $r$. Thus the union bound gives $\Pr[t\in\cR_h]\leq\sum_{r\in\cR}\Pr[F_{r,t}]$ for each $t\in\cR$. By linearity of expectation,
\[
 \mathbb{E}[R_h]
 =\sum_{t\in\cR}\Pr[t\in\cR_h]
 \leq\sum_{r\in\cR}\sum_{t\in\cR}\Pr[F_{r,t}]
 \leq\frac{2}{\theta}\cdot\sum_{r\in\cR}\sum_{t\in\cR}y_{r,t}
 \leq\frac{2\cdot K}{\theta}\cdot\sum_{r\in\cR}y_r
 \leq\frac{2\cdot K^2}{\theta}.
\]
For each $A\in\cA^\ell_{r,s}$, independence of the activation and trial events and the definition of light occurrences give
\[
 \Pr[E_{r,s}\cap J_{r,s,A}]
 =\Pr[E_{r,s}]\cdot\Pr[J_{r,s,A}]
 =\frac{y_r}{s}\cdot\frac{x_A}{y_r}
 =\frac{x_A}{s}<\frac{\theta\cdot y_r}{s^2}.
\]
By linearity of expectation, the above probability bound and $y_r<1/T$,
\[
 \mathbb{E}[R_\ell]
 \leq\sum_{r,s}\sum_{A\in\cA^\ell_{r,s}}\spr{\cR'_A}\cdot\Pr[E_{r,s}\cap J_{r,s,A}]
 \leq\frac{\theta}{T}\cdot\sum_{r,s}\sum_{A\in\cA^\ell_{r,s}}\frac{\spr{\cR'_A}}{s^2}
 \leq\frac{\theta}{T}\cdot\sum_s\sum_{A\in\cA_s}\frac{\spr{\cR'_A}^2}{s^2}
 \leq\frac{4\cdot\theta\cdot m}{T}.
\]
The first inequality counts red elements with multiplicity. The third counts, for each $A\in\cA_s$, at most one occurrence for each of its $\spr{\cR'_A}$ residual red elements. The last inequality uses $\spr{\cR'_A}/s<2$ and the fact that there are at most $m$ sets. Adding $\spr{\cR_+}\leq K\cdot T$ and substituting $\theta=K/T$ and $m=T^3$ gives
\begin{equation}\label{eq:rbsc-cost-expectation}
 \mathbb{E}[R]
 \leq K\cdot T+\frac{2\cdot K^2}{\theta}+\frac{4\cdot\theta\cdot m}{T}
 =3\cdot K\cdot T+\frac{4\cdot K\cdot m}{T^2}
 =7\cdot K\cdot T.
\end{equation}
\end{proof}

To control blue coverage, we use auxiliary \emph{marks} to identify some of the blue elements covered by selected occurrences. For each occurrence of $A$ with $x_A>0$ in group $\cA_{r,s}$, independently mark each $u\in\cB_A\cap\cB'$ using a coin $Z_{r,s,A,u}$ with $\Pr[Z_{r,s,A,u}=1]=a_{u,A}/x_A$. These marking choices are independent of all activations, trials, and other marking choices. The probabilities lie in $[0,1]$ by~\eqref{eq:rbsc-lp-marginal}. For $x_A=0$, take the coins to be always zero. The marking probability is chosen so that, combined with the trial probability, an occurrence contributes in proportion to its assignment mass $a_{u,A}$. Let $\cD_{r,s,A}$ be the set of elements whose marking coins succeed if $J_{r,s,A}$ occurs and the empty set otherwise. The random set of elements marked by selected occurrences in group $\cA_{r,s}$ is $\cB_{r,s}=\bigcup_{A\in\cF_{r,s}}\cD_{r,s,A}$. Define $\widehat{\cB}=\bigcup_{r,s}\cB_{r,s}$ and $Y=\spr{\widehat{\cB}}$. In an active group, a successful trial with no marks still selects the occurrence and its red elements.

\begin{claim}\label{claim:rbsc-blue-coverage}
The expected number of distinct marked blue elements satisfies $\mathbb{E}[Y]>2\cdot k/5$.
\end{claim}
\begin{proof}
Fix $u\in\cB'$. For an occurrence of $A$ in group $\cA_{r,s}$ with $u\in \cB_A$ and $x_A>0$, the probability that its trial succeeds and its marking coin for $u$ succeeds is
\[
 \Pr[u\in \cD_{r,s,A}]=\frac{x_A}{y_r}\cdot\frac{a_{u,A}}{x_A}=\frac{a_{u,A}}{y_r}.
\]
When $x_A=0$, both this probability and $a_{u,A}$ are zero. The sum of these probabilities within the group is
\[
 \lambda_{r,s,u}
 =\frac1{y_r}\cdot\sum_{A\in\cA_{r,s}:u\in \cB_A}a_{u,A}
 \leq1
\]
by~\eqref{eq:rbsc-lp-blue-load}. The choices for the set occurrences are independent. We use the inequality $1-x\leq e^{-x}$ and the concavity of $1-e^{-a\cdot x}$, which gives $1-e^{-a\cdot x}\geq(1-e^{-a})\cdot x$ for $a\geq0$ and $x\in[0,1]$. The group's conditional probability of marking $u$ is therefore at least
\[
 \Pr[u\in\cB_{r,s}\mid E_{r,s}]
 =1-\prod_{A\in\cA_{r,s}:u\in \cB_A}
       \br{1-\frac{a_{u,A}}{y_r}}
 \geq1-e^{-\lambda_{r,s,u}}
 \geq(1-e^{-1})\cdot\lambda_{r,s,u}.
\]
Since $\cB_{r,s}=\emptyset$ when the group is inactive, the preceding bound and the definition of $\lambda_{r,s,u}$ give
\[
 \Pr[u\in\cB_{r,s}]=\Pr[E_{r,s}]\cdot\Pr[u\in\cB_{r,s}\mid E_{r,s}]
 \geq\frac{y_r}{s}\cdot(1-e^{-1})\cdot\lambda_{r,s,u}
 =\frac{1-e^{-1}}{s}\cdot\sum_{A\in\cA_{r,s}:u\in \cB_A}a_{u,A}.
\]
Let $M_u$ be the number of groups that mark $u$. By linearity of expectation and the group bound above,
\begin{align*}
 \mathbb{E}[M_u]&=\sum_{r,s}\Pr[u\in\cB_{r,s}]
 \geq(1-e^{-1})\cdot\sum_{r,s}\frac1s\cdot
       \sum_{A\in\cA_{r,s}:u\in \cB_A}a_{u,A}\\
 &=(1-e^{-1})\cdot\sum_s\sum_{A\in\cA_s:u\in \cB_A}
       \frac{a_{u,A}}s\cdot\sum_{r\in\cR'_A:y_r>0}1\\
 &=(1-e^{-1})\cdot\sum_s\sum_{A\in\cA_s:u\in \cB_A}
       \frac{\spr{\cR'_A}}s\cdot a_{u,A}
 \geq(1-e^{-1})\cdot\sum_{A:u\in \cB_A}a_{u,A}
 =(1-e^{-1})\cdot z_u.
\end{align*}
For the second equality, fix a scale $s$ and a set $A\in\cA_s$ containing $u$. The term $a_{u,A}$ appears in $\sum_r\sum_{A'\in\cA_{r,s}:u\in\cB_{A'}}a_{u,A'}$ once for each $r\in\cR'_A$ with $y_r>0$. If $y_r=0$ for some $r\in\cR'_A$, then $a_{u,A}\leq x_A\leq y_r=0$ by~\eqref{eq:rbsc-lp-marginal} and~\eqref{eq:rbsc-lp-red}, so these pivots can also be counted. For the last inequality, every set $A$ containing $u\in\cB'$ has nonempty $\cR'_A$. Otherwise, it was initially selected and would cover $u$. Such a set belongs to exactly one scale $s$, where $\spr{\cR'_A}/s\geq1$. Since $a_{u,A}\geq0$, replacing this factor by $1$ gives the lower bound.

The rounding choices for distinct group indices are independent. Applying $1-x\leq e^{-x}$ across groups and then the above concavity bound for $z_u\in[0,1]$ yields
\[
 \Pr[u\in\widehat{\cB}]
 =1-\prod_{r,s}\br{1-\Pr[u\in\cB_{r,s}]}
 \geq1-e^{-\mathbb{E}[M_u]}
 \geq1-e^{-(1-e^{-1})\cdot z_u}
 \geq c\cdot z_u,
 \qquad c=1-e^{-(1-e^{-1})}.
\]
Since $c>23/50$, summing over $\cB'$ and using~\eqref{eq:rbsc-residual-mass} gives
\[
 \mathbb{E}[Y]=\sum_{u\in\cB'}\Pr[u\in\widehat{\cB}]\geq c\cdot\sum_{u\in\cB'}z_u
 >\frac{23}{50}\cdot\frac{7\cdot k}{8}
 =\frac{161\cdot k}{400}>\frac{2\cdot k}{5}.
\]
\end{proof}

For each group $\cA_{r,s}$, define
\[
 L_{r,s}=\sum_{A\in\cA_{r,s}}\spr{\cD_{r,s,A}},
 \qquad W_{r,s}=\boldsymbol{1}_{E_{r,s}}\cdot L_{r,s},
 \qquad W=\sum_{r,s}W_{r,s}.
\]
Thus $W_{r,s}$ counts the marks in group $\cA_{r,s}$ with multiplicity over its selected occurrences. A blue element marked by two occurrences is counted twice in $W$, even if the occurrences are in the same group. In particular, $Y\leq W$.

\begin{claim}\label{claim:rbsc-second-moment}
We have $\mathbb{E}[W^2]\leq10\cdot k^2$.
\end{claim}
\begin{proof}
Fix a group $\cA_{r,s}$. For each occurrence $A\in\cA_{r,s}$, let $X_A=\spr{\cD_{r,s,A}}$, so $L_{r,s}=\sum_{A\in\cA_{r,s}}X_A$. These variables are defined before activation and are independent across occurrences. By linearity of expectation and the marking probabilities calculated above,
\[
 \mathbb{E}[X_A]=\sum_{u\in\cB_A\cap\cB'}\Pr[u\in\cD_{r,s,A}]
 =\frac1{y_r}\cdot\sum_{u\in \cB_A\cap\cB'}a_{u,A}.
\]
For the second moment, put $p_{u,A}=\Pr[Z_{r,s,A,u}=1]$ and $d_A=\sum_{u\in\cB_A\cap\cB'}p_{u,A}$. Let $N_A=\sum_{u\in\cB_A\cap\cB'}Z_{r,s,A,u}$. By~\eqref{eq:rbsc-lp-set}, $d_A\leq k$. The marking coins are independent Bernoulli variables, so
\[
 \mathbb{E}[N_A]=d_A,\qquad
 \operatorname{Var}(N_A)=\sum_{u\in\cB_A\cap\cB'}p_{u,A}\cdot(1-p_{u,A}).
\]
Moreover, $X_A=\boldsymbol{1}_{J_{r,s,A}}\cdot N_A$ and the trial is independent of $N_A$, so $\mathbb{E}[X_A]=(x_A/y_r)\cdot d_A$. Using $\mathbb{E}[N_A^2]=\mathbb{E}[N_A]^2+\operatorname{Var}(N_A)$ gives
\[
 \mathbb{E}[X_A^2]=\frac{x_A}{y_r}\cdot\br{d_A^2+\sum_{u\in\cB_A\cap\cB'}p_{u,A}\cdot(1-p_{u,A})}
 \leq\frac{x_A}{y_r}\cdot(d_A^2+d_A)
 \leq(k+1)\cdot\mathbb{E}[X_A].
\]
Writing $\mu=\mathbb{E}[L_{r,s}]$, the first-moment calculation and $r\in\cR_A$ for every $A\in\cA_{r,s}$ give
\[
 \mu=\frac1{y_r}\cdot\sum_{A\in\cA_{r,s}}\sum_{u\in\cB_A\cap\cB'}a_{u,A}
 \leq\frac1{y_r}\cdot\sum_{A:r\in\cR_A}\sum_{u\in\cB_A}a_{u,A}\leq k,
\]
where the last inequality follows from~\eqref{eq:rbsc-lp-total-load}. Expanding $L_{r,s}^2$ and using independence across distinct occurrences gives
\begin{align*}
 \mathbb{E}[L_{r,s}^2]
 &=\sum_{A\in\cA_{r,s}}\mathbb{E}[X_A^2]+\sum_{A,A'\in\cA_{r,s}:A\ne A'}\mathbb{E}[X_A]\cdot\mathbb{E}[X_{A'}]\\
 &\leq(k+1)\cdot\sum_{A\in\cA_{r,s}}\mathbb{E}[X_A]+\br{\sum_{A\in\cA_{r,s}}\mathbb{E}[X_A]}^2
 =(k+1)\cdot\mu+\mu^2\leq(2k+1)\cdot\mu.
\end{align*}
The first inequality uses the bound on $\mathbb{E}[X_A^2]$ and adds the nonnegative terms with $A=A'$ to the cross terms. The last inequality uses $\mu\leq k$.
The variable $L_{r,s}$ is independent of activation. Multiplying the last bound by $y_r/s$ therefore gives
\begin{equation}\label{eq:rbsc-group-second-moment}
 \mathbb{E}[W_{r,s}^2]\leq(2k+1)\cdot\mathbb{E}[W_{r,s}].
\end{equation}
Moreover, summing the expected number of marks over the groups yields
\[
 \mathbb{E}[W]
 =\sum_{r,s}\frac1s\sum_{A\in\cA_{r,s}}
       \sum_{u\in \cB_A\cap\cB'}a_{u,A}
 =\sum_s\sum_{A\in\cA_s}\frac{\spr{\cR'_A}}s\cdot
       \sum_{u\in \cB_A\cap\cB'}a_{u,A}
 \leq2\cdot\sum_{u\in\cB'}\sum_{A\ni u}a_{u,A}
 =2\cdot\sum_{u\in\cB'}z_u\leq2\cdot k.
\]
As in the coverage calculation, omitted zero-$y_r$ pivots contribute zero. Finally, independence of the rounding choices for distinct group indices and~\eqref{eq:rbsc-group-second-moment} imply
\[
 \mathbb{E}[W^2]
 =\sum_{r,s}\mathbb{E}[W_{r,s}^2]
   +\sum_{r,s}\sum_{\substack{r',s'\\(r',s')\ne(r,s)}}\mathbb{E}[W_{r,s}]\cdot\mathbb{E}[W_{r',s'}]
 \leq(2k+1)\cdot\mathbb{E}[W]+\br{\mathbb{E}[W]}^2
 \leq8\cdot k^2+2\cdot k\leq10\cdot k^2.
\]
\end{proof}

We use a \emph{potential}, a score assigned to each outcome of the rounding, to find one outcome with both sufficient coverage and small red cost. We start with the number $Y$ of marked blue elements and subtract the coverage target $k/8$ and a penalty for the red cost bound $R$. A positive score then guarantees the desired coverage, but a large value of $Y$ could still offset a large red cost. To prevent this, we also subtract a quadratic penalty in $W$. Since $W\geq Y$, this limits how much the coverage reward can offset the red cost, while the bound on $\mathbb{E}[W^2]$ keeps the expected penalty small. We choose the coefficients so that the expected score remains positive, and later use conditional expectations to find an outcome with positive score deterministically. Define
\begin{equation}\label{eq:rbsc-potential}
 \Phi=Y-\frac{W^2}{80\cdot k}-\frac{k\cdot R}{70\cdot K\cdot T}-\frac{k}{8}.
\end{equation}
\begin{claim}\label{claim:rbsc-positive-potential}
We have $\mathbb{E}[\Phi]>0$. Every outcome with $\Phi>0$ covers at least $k/8$ blue elements and has red cost smaller than $1400\cdot K\cdot T$.
\end{claim}
\begin{proof}
Claims~\ref{claim:rbsc-red-cost}, \ref{claim:rbsc-blue-coverage}, and~\ref{claim:rbsc-second-moment} give
\[
 \mathbb{E}[\Phi]
 >\frac{2\cdot k}{5}-\frac{10\cdot k^2}{80\cdot k}-\frac{k\cdot7\cdot K\cdot T}{70\cdot K\cdot T}-\frac{k}{8}
 =\frac{k}{20}>0.
\]
If $\Phi>0$, all three subtracted terms are nonnegative, so $Y>k/8$. Each of these $Y$ marked elements is covered by the output. Furthermore, $W\geq Y$ implies
\[
 \frac{k\cdot R}{70\cdot K\cdot T}
 <Y-\frac{W^2}{80\cdot k}-\frac{k}{8}
 \leq Y-\frac{Y^2}{80\cdot k}
 =20\cdot k-\frac{(Y-40\cdot k)^2}{80\cdot k}
 \leq20\cdot k.
\]
It follows that $R<1400\cdot K\cdot T$, and the actual red cost is at most $R$.
\end{proof}

\begin{claim}\label{claim:rbsc-conditional-expectations}
An outcome with $\Phi>0$ can be found deterministically in polynomial time.
\end{claim}
\begin{proof}
For the analysis, regard all activation, trial, and marking coins as drawn in advance. The deterministic algorithm fixes their values rather than sampling them. Process the groups in a fixed order, first fixing their activation, and then, for an active group, fixing each occurrence's trial and, if it succeeds, its marking coins. At each step choose a possible value maximizing the conditional expectation of $\Phi$.

Fix a history of exposed coins, and let $\mathcal{E}$ be the event that they take their recorded values. We only expose values of positive conditional probability. Since $\mathcal{E}$ is an intersection of individual coin outcomes, all unfixed coins remain independent. The conditional probability that a coin succeeds is its original probability if it is unfixed, and $0$ or $1$ otherwise. In particular, the original marking probability is $a_{u,A}/x_A$ when $x_A>0$ and zero when $x_A=0$.

For $u\in\cB'$ and $t\in\cR\setminus\cR_+$, independence within each group conditional on $\mathcal{E}$ gives
\[
 \Pr[u\in\cD_{r,s,A}\mid\mathcal{E}]
 =\Pr[J_{r,s,A}\mid\mathcal{E}]\cdot\Pr[Z_{r,s,A,u}=1\mid\mathcal{E}]
 \quad\text{for }u\in\cB_A\cap\cB',
\]
and the probabilities that the group misses a blue or red element are
\[
 \begin{aligned}
 \Pr[u\notin\cB_{r,s}\mid\mathcal{E}]
 &=1-\Pr[E_{r,s}\mid\mathcal{E}]+\Pr[E_{r,s}\mid\mathcal{E}]\cdot\prod_{A\in\cA_{r,s}:u\in\cB_A}\br{1-\Pr[u\in\cD_{r,s,A}\mid\mathcal{E}]},\\
 \Pr[t\notin\cR_{r,s}\mid\mathcal{E}]
 &=1-\Pr[E_{r,s}\mid\mathcal{E}]+\Pr[E_{r,s}\mid\mathcal{E}]\cdot\prod_{A\in\cA_{r,s}:t\in\cR'_A}\br{1-\Pr[J_{r,s,A}\mid\mathcal{E}]}.
 \end{aligned}
\]
Independence of distinct groups and linearity of expectation then give
\begin{equation}\label{eq:rbsc-conditional-coverage-cost}
 \begin{aligned}
 \mathbb{E}[Y\mid\mathcal{E}]
 &=\sum_{u\in\cB'}\br{1-\prod_{r,s}\Pr[u\notin\cB_{r,s}\mid\mathcal{E}]},\\
 \mathbb{E}[R\mid\mathcal{E}]
 &=\spr{\cR_+}+\sum_{t\in\cR\setminus \cR_+}\br{1-\prod_{r,s}\Pr[t\notin\cR_{r,s}\mid\mathcal{E}]}.
 \end{aligned}
\end{equation}
For the second moment, fix a group $\cA_{r,s}$ and use the variables $N_A$ and $X_A$ defined in the proof of Claim~\ref{claim:rbsc-second-moment}. Conditional on $\mathcal{E}$, the marking coins and trial remain independent, so
\begin{align*}
 \mathbb{E}[N_A\mid\mathcal{E}]&=\sum_{u\in\cB_A\cap\cB'}\Pr[Z_{r,s,A,u}=1\mid\mathcal{E}],\\
 \mathbb{E}[X_A\mid\mathcal{E}]&=\Pr[J_{r,s,A}\mid\mathcal{E}]\cdot\mathbb{E}[N_A\mid\mathcal{E}],\\
 \mathbb{E}[X_A^2\mid\mathcal{E}]&=\Pr[J_{r,s,A}\mid\mathcal{E}]\cdot\br{\mathbb{E}[N_A\mid\mathcal{E}]^2+\sum_{u\in\cB_A\cap\cB'}\Pr[Z_{r,s,A,u}=1\mid\mathcal{E}]\cdot\br{1-\Pr[Z_{r,s,A,u}=1\mid\mathcal{E}]}}.
\end{align*}
The variables $X_A$ remain independent across occurrences, and $L_{r,s}$ remains independent of activation. Thus
\begin{align*}
 \mathbb{E}[L_{r,s}\mid\mathcal{E}]&=\sum_{A\in\cA_{r,s}}\mathbb{E}[X_A\mid\mathcal{E}],\\
 \mathbb{E}[L_{r,s}^2\mid\mathcal{E}]&=\mathbb{E}[L_{r,s}\mid\mathcal{E}]^2+\sum_{A\in\cA_{r,s}}\br{\mathbb{E}[X_A^2\mid\mathcal{E}]-\mathbb{E}[X_A\mid\mathcal{E}]^2},\\
 \mathbb{E}[W_{r,s}\mid\mathcal{E}]&=\Pr[E_{r,s}\mid\mathcal{E}]\cdot\mathbb{E}[L_{r,s}\mid\mathcal{E}],\\
 \mathbb{E}[W_{r,s}^2\mid\mathcal{E}]&=\Pr[E_{r,s}\mid\mathcal{E}]\cdot\mathbb{E}[L_{r,s}^2\mid\mathcal{E}].
\end{align*}
The group totals remain independent under $\mathcal{E}$. Therefore
\begin{equation}\label{eq:rbsc-conditional-second-moment}
 \mathbb{E}[W^2\mid\mathcal{E}]
 =\br{\sum_{r,s}\mathbb{E}[W_{r,s}\mid\mathcal{E}]}^2
  +\sum_{r,s}\br{\mathbb{E}[W_{r,s}^2\mid\mathcal{E}]-\mathbb{E}[W_{r,s}\mid\mathcal{E}]^2}.
\end{equation}
Substituting~\eqref{eq:rbsc-conditional-coverage-cost} and~\eqref{eq:rbsc-conditional-second-moment} into~\eqref{eq:rbsc-potential} computes $\mathbb{E}[\Phi\mid\mathcal{E}]$ in polynomial time. A polynomial-bit rational LP solution suffices, and comparisons involving $T=m^{1/3}$ use exact arithmetic in a fixed-degree algebraic extension. The same formulas compute the conditional expectation for each possible value of the next coin. By averaging, one such value does not decrease the conditional expectation. There are polynomially many coins, so fixing them as above preserves the positive initial expectation from Claim~\ref{claim:rbsc-positive-potential} in polynomial time. The unexposed coins in inactive groups or failed trials cannot affect $\Phi$, so the resulting value is positive.
\end{proof}

For each feasible guess, retain the initially selected family if it already meets the coverage threshold, or use Claim~\ref{claim:rbsc-conditional-expectations} to obtain a candidate. Return a candidate of minimum actual red cost. The correct guess $K=\OPT$ is feasible by Claim~\ref{claim:rbsc-lp-validity}, and its candidate covers at least $k/8$ blue elements and costs at most $1400\cdot K\cdot T$. Every retained candidate meets the same coverage threshold. There are at most $\spr{\cR}$ guesses, proving the theorem. The case $k=0$, if allowed, is handled by returning the empty family.
\end{proof}

Repeating Theorem~\ref{thm:partial-red-blue-bicriteria} logarithmically many times on the remaining blue target yields an approximation that meets the full target. The original optimum remains feasible for the residual target in each iteration, so the red cost in each iteration is bounded in terms of the original optimum.
\begin{proposition}\label{pro:partial-red-blue}
    Instances of $\ProblemPRBSC$ with $m$ sets and $n\geq2$ blue elements admit a deterministic polynomial-time $\alpha_{m,n}$-approximation algorithm, where $\alpha_{m,n}$ is a known bound satisfying
    \[
    \alpha_{m,n}=\bigo\br{m^{1/3}\cdot\log n}.
    \]
    For $n\leq1$, the problem can be solved optimally, so we take $\alpha_{m,n}=1$.
\end{proposition}

\subsection{$\ProblemPCSC$ and $\ProblemBPCSC$ via Partial Red-Blue Set Cover}
\label{subsection:PCSC}\label{subsection:BPCSC}
We use the same exact reduction for both covering variants.
Given a set cover instance $(\cU,\cS,\preceq)$, create a red element $r_S$ for each $S\in\cS$ and a blue element $b_u$ for each $u\in\cU$. For each $S\in\cS$, let $S^{+}=\closure{S}$ and create a red-blue set $A_S=\brc{r_T:T\in S^{+}}\cup\brc{b_u:u\in\cov\br{S^{+}}}$.
The instance has one available set $A_S$ for each original set $S$. For any selected subfamily indexed by $\mathcal{J}\subseteq\cS$, define a precedence-closed family $\cC_{\mathcal{J}}=\bigcup_{S\in\mathcal{J}}S^{+}$.
The red elements covered by the selected red-blue sets form $\brc{r_T:T\in\cC_{\mathcal{J}}}$, and the blue elements covered form $\brc{b_u:u\in\cov\br{\cC_{\mathcal{J}}}}$.
Thus, the red cost and blue coverage equal the size and coverage of $\cC_{\mathcal{J}}$, respectively.
Conversely, for any precedence-closed family $\cC\subseteq\cS$, selecting $A_S$ for every $S\in\cC$ covers the red elements corresponding to $\cC$ and the blue elements corresponding to $\cov\br{\cC}$, and no others: each $S^{+}\subseteq\cC$, and every $S\in\cC$ belongs to $S^{+}$. Hence, the reduction preserves cost and coverage in both directions.

\begin{theorem}\label{thm:PCSC-BPCSC-RBSC}\label{thm:PCSC-RBSC}\label{thm:BPCSC}
There are deterministic polynomial-time algorithms with approximation ratio $\alpha_{m,n}$ for $\ProblemPCSC$ and bicriteria ratio $\br{\alpha_{m,n},1}$ for $\ProblemBPCSC$. In the budgeted case, the output is a precedence-closed family of size at most $\alpha_{m,n}\cdot\budget$ whose coverage is at least the optimum under budget $\budget$.
\end{theorem}
\begin{proof}
For $\ProblemPCSC$, apply the above construction and for the input for $\ProblemPRBSC$ take $k=\cl{f\cdot n}$. The output translates to a solution to $\ProblemPCSC$ as described, and the result for the latter follows from Proposition~\ref{pro:partial-red-blue}.

For $\ProblemBPCSC$, run the algorithm from Proposition~\ref{pro:partial-red-blue} for each integer target $k\in[\spr{\cov\br{\cS,\cU}}]$, converting each output to a precedence-closed family. Also include the empty family as a candidate, and return the candidate of largest coverage whose size is at most $\alpha_{m,n}\cdot\budget$. Let $\cC^*$ be an optimal family under budget $\budget$, and let $t^*=\spr{\cov\br{\cC^*,\cU}}$. If $t^*=0$, the empty family is optimal. Otherwise, the red-blue instance with target $t^*$ has optimum red cost at most $\spr{\cC^*}\leq\budget$. Its $\alpha_{m,n}$-approximate solution converts to a family of size at most $\alpha_{m,n}\cdot\budget$ covering at least $t^*$ elements. This candidate is considered by the algorithm, so the returned family covers at least as many elements as $\cC^*$. There are at most $n$ target values, so the algorithm runs in polynomial time.
\end{proof}

\begin{corollary}\label{cor:PCSC-BPCSC-bicriteria}
There are deterministic polynomial-time $\br{\bigo\br{m^{1/3}},8}$-approximation algorithms for $\ProblemPCSC$ and $\ProblemBPCSC$.
\end{corollary}
\begin{proof}
For $\ProblemPCSC$, apply Theorem~\ref{thm:partial-red-blue-bicriteria} to the reduction above with $k=\cl{f\cdot n}$. The resulting family has size at most $1400\cdot m^{1/3}$ times the optimum and covers at least $k/8\geq f\cdot n/8$ elements.

For $\ProblemBPCSC$, try all integer blue targets as in Theorem~\ref{thm:PCSC-BPCSC-RBSC}, retaining candidates of cost at most $1400\cdot m^{1/3}\cdot\budget$. Also include the empty family and return the retained candidate of largest coverage. If the optimum budgeted coverage is $t^*>0$, the red-blue instance with target $t^*$ has optimum red cost at most $\budget$. Theorem~\ref{thm:partial-red-blue-bicriteria} therefore supplies a retained candidate covering at least $t^*/8$ elements. If $t^*=0$, the empty family suffices. All calls and choices are deterministic.
\end{proof}

\begin{corollary}\label{cor:bicriteria-decision-trees}
There are deterministic polynomial-time $\bigo\br{m^{1/3}\log n}$-approximation algorithms for $\ProblemPCWCDT$ and $\ProblemPCACDT$ under general precedence constraints.
\end{corollary}
\begin{proof}
For $\ProblemPCWCDT$, combine Corollary~\ref{cor:PCSC-BPCSC-bicriteria} with Theorem~\ref{thm:PCSC-to-PCWCDT}. For $\ProblemPCACDT$, combine the budgeted guarantee in Corollary~\ref{cor:PCSC-BPCSC-bicriteria} with Theorems~\ref{thm:BPCSC-to-PCMSSC} and~\ref{thm:PCMSSC-to-PCACDT}. In both cases the coverage-loss factor is the constant $8$, and every step of the covering-to-tree reductions is deterministic.
\end{proof}

Trying all integer budgets $\budget\in[m]$ includes the optimal budget $\budget^*=\spr{\cCopt}$. Applying a $\br{\alpha,\beta}$-approximation for $\ProblemBPCSC$ and returning the smallest family with coverage at least $f\cdot n/\beta$ therefore gives the same guarantee for $\ProblemPCSC$.\par\endgroup
\begin{corollary}\label{cor:BPCSC-to-PCSC}
    If there exists a polynomial-time $(\alpha,\beta)$-approximation algorithm for $\ProblemBPCSC$, then there exists a polynomial-time $(\alpha,\beta)$-approximation algorithm for $\ProblemPCSC$.
\end{corollary}


\subsection{$\ProblemPCMSSC$ via $\ProblemBPCSC$} \label{subsection:PCMSSC}
We show how to use an $(\alpha,\beta)$-approximation algorithm for $\ProblemBPCSC$ to obtain an $\br{\bigo\br{\alpha\cdot\beta^3}, \beta}$-approximation for $\ProblemPCMSSC$.  Our approach is reminiscent of the ideas used for solving problems regarding \textsc{Minimum Latency TSP}~\cite{PathsTreesMinimumLatencyTours,KTravelingRepairmenProblem} and \textsc{Adaptive TSP}~\cite{ApproxAlgsForOptDTsAndAdapTSPProblems}. The overarching theme of this connection is that one can treat appending sets to the covering sequence as a kind of tour on a DAG induced by the precedence constraints, and the cost of covering an element as a latency of `visiting' that element. Note that, however, this intuition is not exact and is never used directly neither in the procedure nor its analysis.

Let $\alpha,\beta\geq 1$ and $a=\frac{3\cdot\beta-1}{3\cdot\beta-2}$, so $1<a\leq 2$.
% Denote by $\cCopt$ any optimal solution to $\ProblemPCMSSC$ on the input $(\cU, \cS, \preceq, f)$.
Let $l^*=\max\brc{1,\cl{\log_a\spr{\cCopt}}}$, where $\cCopt$ is an optimal solution to $\ProblemPCMSSC$.
So, $a^{l^*-1}\leq\spr{\cCopt}\leq a^{l^*}$.
We start with pseudocode for $\ProblemPCMSSC$ in Algorithm~\ref{alg:fPCMSSC}.
\input{pseudocodes/f_PCMSSC.tex}
Each family returned by $\ProblemBPCSC$ is precedence-closed, so the family $P_l$ of sets already appended is also precedence-closed. When a family is appended, only sets outside $P_l$ are used and they are ordered by $\operatorname{ord}$. Every predecessor of a new set is therefore either already in the sequence or earlier in the appended block. The same holds for the padding and the final family, so every sequence considered by the algorithm is precedence-closed and contains no repeated sets. In the analysis, $\pi_l$ denotes the padded prefix before the final family is appended.
We start with a lemma that relates the coverage times and the lengths of $\pi_{l^*}$ and $\cCopt$.
    \begin{lemma}\label{lem:pi-spread-cost}
        We have that $\spr{\pi_{l^*}} = \bigo\br{\alpha \cdot \beta}\cdot \spr{\cCopt}$, and if $\spr{\pi_{l^*}}<m$, then $\spr{\pi_{l^*}}=\Omega\br{\alpha\cdot\beta}\cdot\spr{\cCopt}$. Moreover, $\coverageTime\br{\pi_{l^*},\cU} = \bigo\br{\alpha\cdot\beta^3}\cdot \coverageTime\br{\cCopt,\cU}$.
    \end{lemma}
    \begin{proof}
        We observe that since we used an $\br{\alpha, \beta}$-approximation algorithm for $\ProblemBPCSC$ in each iteration of the inner for loop, we have that for each $1\leq i\leq l^*$, $\spr{\tau_{l^*}^i} \leq \alpha \cdot a^{i+1}$. Thus, the length after padding satisfies:
        \begin{equation} \label{eq:pi}
        \spr{\pi_{l^*}} \leq \max\brc{\alpha\cdot \sum_{i=1}^{l^*} a^{i+1},\min\brc{m,\cl{\alpha\cdot\beta\cdot a^{l^*}}}}\leq \frac{\alpha\cdot a^{l^*+3}}{a-1}\leq \frac{\alpha\cdot a^{4}}{a-1}\cdot\spr{\cCopt}=\bigo\br{\alpha\cdot\beta}\cdot\spr{\cCopt}.
        \end{equation}
        Here we used $\cl{x}\leq x+1$, $\alpha\cdot a^{l^*}\geq1$, $\beta\leq1/(a-1)$, and $a^{l^*}\leq a\cdot\spr{\cCopt}$. If $\spr{\pi_{l^*}}<m$, the padding target is not capped by $m$, and hence $\spr{\pi_{l^*}}\geq\alpha\cdot\beta\cdot a^{l^*}\geq\alpha\cdot\beta\cdot\spr{\cCopt}$. If $\spr{\pi_{l^*}}=m$, then the prefix contains every set in $\cS$. This case will be handled after the latency bound.

        For every $i\in [l^*]$, let $\ell_i=\min\brc{\spr{\cCopt},\fl{a^i}}$ and $n_i^*=\spr{\cov\br{\pref{\cCopt}{\ell_i}}}$, so $n_{l^*}^* = \spr{\cov\br{\cCopt}}$. Let $n_i=\spr{\cov\br{\bigcup_{j=1}^{i}\tau_{l^*}^j}}$ and $n_0=n_0^*=0$. We have:
        \begin{align*}
            &\coverageTime\br{\pi_{l^*},\cU}\leq \sum_{i=1}^{l^*}\br{n_i-n_{i-1}}\cdot \sum_{j=1}^{i}\alpha\cdot a^{j+1} + \br{n-n_{l^*}}\cdot \spr{\pi_{l^*}}
            \\&\leq
            \sum_{i=1}^{l^*}\br{n_i-n_{i-1}}\cdot \frac{\alpha\cdot a^{i+2}}{a-1} + \br{n-n_{l^*}}\cdot \spr{\pi_{l^*}}
            \\&=
            \sum_{i=1}^{l^*}\br{\br{n-n_{i-1}}-\br{n-n_i}}\cdot \frac{\alpha\cdot a^{i+2}}{a-1} + \br{n-n_{l^*}}\cdot \spr{\pi_{l^*}} \leq
            \sum_{i=0}^{l^*}\br{n-n_i}\cdot \frac{\alpha\cdot a^{i+3}}{a-1} =: Q.
        \end{align*}
        Here the last inequality follows from \eqref{eq:pi}.
        Moreover, we have that:
        \begin{align*}
            &2\cdot\coverageTime\br{\cCopt,\cU}\geq a^{l^*-1}\cdot\br{n-n_{l^*-1}^*}+ \sum_{i=1}^{l^*-1}a^{i-1}\cdot\br{n_i^*-n_{i-1}^*}+\br{n-n_{l^*}^*}\cdot\spr{\cCopt}
            \\&\geq
        a^{l^*-1}\cdot\br{n-n_{l^*-1}^*}+ \sum_{i=1}^{l^*-1}a^{i-1}\cdot\br{\br{n-n_{i-1}^*}-\br{n-n_{i}^*}}+\br{n-n_{l^*}^*}\cdot a^{l^*-1}
            \\&=
        \br{n-n_0^*}+\sum_{i=1}^{l^*-1}\br{a^{i}-a^{i-1}}\cdot\br{n-n_{i}^*}+\br{n-n_{l^*}^*}\cdot a^{l^*-1} \geq
        \br{1-\frac{1}{a}}\cdot\sum_{i=0}^{l^*}a^{i}\cdot \br{n-n_i^*}.
        \end{align*}

        Consider any iteration $i\in \brc{1,\dots,l^*}$ of the inner for loop. Let $\cR_{i-1}=\cU\setminus\cov\br{\bigcup_{j=1}^{i-1}\tau_{l^*}^j}$ be the algorithmic residual at the beginning of iteration $i$. The family $\pref{\cCopt}{\ell_i}$ is precedence-closed, has size $\ell_i\leq a^i\leq a^{i+1}$, and is therefore feasible for the $i$-th $\ProblemBPCSC$ instance. Since it covers $n_i^*$ elements in total and the previously computed solutions cover $n_{i-1}$ elements, it covers at least $n_i^*-n_{i-1}$ elements in $\cR_{i-1}$.
        Thus, $n_i^*-n_{i-1}$ lower bounds the optimum residual coverage in this iteration.
        Hence, by the $\br{\alpha,\beta}$-approximation guarantee, $n_i-n_{i-1}\geq\frac{n_i^*-n_{i-1}}{\beta}$. Rearranging gives $n-n_i\leq\frac{\beta-1}{\beta}\cdot\br{n-n_{i-1}}+\frac{1}{\beta}\cdot\br{n-n_i^*}$.
        Thus,
        \begin{align*}
            &\frac{\br{a-1}\cdot Q}{\alpha}
            =
            \sum_{i=0}^{l^*}a^{i+3}\cdot \br{n-n_i} \leq
            a^3\cdot n + \frac{1}{\beta}\cdot\sum_{i=1}^{l^*}a^{i+3}\cdot \br{n-n_i^*} + \frac{\beta-1}{\beta}\cdot\sum_{i=1}^{l^*}a^{i+3}\cdot \br{n-n_{i-1}}
            \\&\leq
            \frac{2\cdot a^4}{a-1}\cdot\coverageTime\br{\cCopt,\cU}+\frac{\beta-1}{\beta}\cdot\sum_{i=1}^{l^*}a^{i+3}\cdot \br{n-n_{i-1}}
            \\&=
            \frac{2\cdot a^4}{a-1}\cdot\coverageTime\br{\cCopt,\cU}+\frac{\br{\beta-1}\cdot a}{\beta}\cdot\sum_{i=0}^{l^*-1}a^{i+3}\cdot \br{n-n_{i}} \leq
            \frac{2\cdot a^4}{a-1}\cdot\coverageTime\br{\cCopt,\cU}+\frac{\br{\beta-1}\cdot a}{\beta}\cdot\br{a-1}\cdot\frac{Q}{\alpha}.
        \end{align*}
        Rearranging and substituting $a=(3\cdot\beta-1)/(3\cdot\beta-2)$ gives
        \begin{align*}
            \frac{Q}{\alpha\cdot\coverageTime\br{\cCopt,\cU}}
            &\leq \frac{2\cdot a^4}{(a-1)^2\cdot\br{1-\frac{(\beta-1)\cdot a}{\beta}}}
            =\frac{2\cdot\br{\frac{3\cdot\beta-1}{3\cdot\beta-2}}^4}{\br{\frac{3\cdot\beta-1}{3\cdot\beta-2}-1}^2\cdot\br{1-\frac{(\beta-1)\cdot(3\cdot\beta-1)}{\beta\cdot(3\cdot\beta-2)}}} \\
            &\leq \frac{2\cdot(3\cdot\beta-1)^2\cdot a^4}{1-\frac{(\beta-1)\cdot a}{\beta}}
            \leq\frac{2\cdot(3\cdot\beta-1)^2\cdot a^4}{1-\frac{\beta-2/3}{\beta}}
            =3\cdot\beta\cdot(3\cdot\beta-1)^2\cdot a^4
            \leq432\cdot\beta^3.
        \end{align*}
        Here $(a-1)^{-2}=(3\cdot\beta-2)^2\leq(3\cdot\beta-1)^2$, and $1-(\beta-1)\cdot a/\beta=(2\cdot\beta-1)/(\beta\cdot(3\cdot\beta-2))\geq2/(3\cdot\beta)$ for $\beta\geq1$. The final inequality uses $a\leq2$ and $3\cdot\beta-1\leq3\cdot\beta$.
        The lemma follows.
    \end{proof}

    If $\spr{\pi_{l^*}}=m$, then $\pi_{l^*}$ contains every set in $\cS$, and thus covers every element covered by $\cCopt$. The candidate is feasible and its latency is bounded by Lemma~\ref{lem:pi-spread-cost}. Otherwise, let $P_{l^*}$ be the family of sets in $\pi_{l^*}$, let $\cR_{l^*}=\cU\setminus\cov\br{P_{l^*}}$, and let $r=\spr{\cov\br{P_{l^*},\cU}}$.
    \begin{lemma}\label{lem:sigma-coverage}
        We have that $\spr{\cov\br{\sigma_{l^*},\cR_{l^*}}} \geq \frac{\max\brc{0,f\cdot n-r}}{\beta}$ and $\spr{\sigma_{l^*}} = \bigo\br{\alpha}\cdot \spr{\cCopt}$.
    \end{lemma}
    \begin{proof}
        Since $\cCopt$ satisfies $\spr{\cCopt}\leq a^{l^*}$, it is feasible for the final $\ProblemBPCSC$ instance on residual universe $\cR_{l^*}$. It covers at least $\max\brc{0,f\cdot n-r}$ elements of that residual. The approximation guarantee gives the coverage bound, while $\spr{\sigma_{l^*}}\leq\alpha\cdot a^{l^*}\leq\alpha\cdot a\cdot\spr{\cCopt}=\bigo\br{\alpha}\cdot\spr{\cCopt}$ gives the size bound.
    \end{proof}
    Let $\pi_{l^*}^+=\pi_{l^*}\circ\operatorname{ord}\br{\sigma_{l^*}\setminus P_{l^*}}$ denote the sequence obtained by appending only the final solution's new sets.
    \begin{lemma}\label{lem:combined-coverage-cost}
        We have that $\spr{\cov\br{\pi_{l^*}^+,\cU}}\geq \frac{f\cdot n}{\beta}$ and $\coverageTime\br{\pi_{l^*}^+,\cU} = \bigo\br{\alpha\cdot\beta^3}\cdot \coverageTime\br{\cCopt,\cU}$.
    \end{lemma}
    \begin{proof}
        By Lemma~\ref{lem:sigma-coverage}, the prefix and the final solution together cover at least $r+\frac{\max\brc{0,f\cdot n-r}}{\beta}\geq\frac{f\cdot n}{\beta}$ elements. Here the residual coverage from $\sigma_{l^*}$ is disjoint from the prefix coverage by definition of $\cR_{l^*}$.
        For each element $u\in\cU$, let $t_u$ denote the index of the first set in $\pi_{l^*}$ that covers $u$ if $u$ is covered by $\pi_{l^*}$, otherwise set $t_u=\spr{\pi_{l^*}}$.
        Lemma \ref{lem:pi-spread-cost} implies that 
        \[
        \coverageTime\br{\pi_{l^*},\cU}=\sum_{u\in\cU} t_u = \bigo\br{\alpha\cdot\beta^3}\cdot \coverageTime\br{\cCopt,\cU}.
        \]
        Observe, that for each $u\in\cov\br{\pi_{l^*}}$, its coverage time in $\pi_{l^*}^+$ is also $t_u$.
        For each $u\notin\cov\br{\pi_{l^*}}$, we have $t_u=\spr{\pi_{l^*}}$. Since this case has $\spr{\pi_{l^*}}<m$, the padding guarantee gives $\spr{\pi_{l^*}}\geq\alpha\cdot\beta\cdot a^{l^*}$. The appended suffix contains at most $\spr{\sigma_{l^*}}\leq\alpha\cdot a^{l^*}\leq\spr{\pi_{l^*}}/\beta$ new sets. Thus the coverage time of $u$ in $\pi_{l^*}^+$ is at most $(1+1/\beta)\cdot t_u\leq2\cdot t_u$.
        The explicit bound in the proof of Lemma~\ref{lem:pi-spread-cost} therefore gives $\coverageTime\br{\pi_{l^*}^+,\cU}\leq2\cdot\coverageTime\br{\pi_{l^*},\cU}\leq864\cdot\alpha\cdot\beta^3\cdot\coverageTime\br{\cCopt,\cU}=\bigo\br{\alpha\cdot\beta^3}\cdot\coverageTime\br{\cCopt,\cU}$.
    \end{proof}
Since $\log a=\Theta(1/\beta)$, Algorithm~\ref{alg:fPCMSSC} makes $\bigo(\beta^2\log^2 m)$ calls to the budgeted algorithm. Its running time is therefore polynomial whenever $\beta$ is polynomially bounded in the input size. All applications below use constant $\beta$.
By Lemma~\ref{lem:combined-coverage-cost}, the candidate for $l^*$ meets the coverage requirement and has the stated latency bound. Since Algorithm~\ref{alg:fPCMSSC} returns the minimum-latency candidate meeting that coverage requirement, the following theorem follows.
\begin{theorem}\label{thm:BPCSC-to-PCMSSC}
    \setlength{\emergencystretch}{2em}
    If there exists a polynomial-time bicriteria $(\alpha,\beta)$-approximation algorithm for $\ProblemBPCSC$, with $\beta$ polynomially bounded in the input size, then there exists a polynomial-time bicriteria $\br{\bigo\br{\alpha\cdot\beta^3}, \beta}$-approximation algorithm for $\ProblemPCMSSC$.
\end{theorem}
It should be noted that in all cases when we use Theorem~\ref{thm:BPCSC-to-PCMSSC} we will have $\beta=\bigo\br{1}$, thus yielding a $\br{\bigo\br{\alpha}, \bigo\br{1}}$-approximation algorithm for $\ProblemPCMSSC$.

\subsection{Special cases of precedence constraints} \label{subsection:SpecialCases}
In \emph{budgeted Maximum Coverage}, the input consists of a universe $\cX$, an indexed family $\cA$ of subsets of $\cX$, costs $c:\cA\to\mathbb{R}_{\geq0}$ and a budget $B>0$. The goal is to maximize $\spr{\cov\br{\cA'}}$ over $\cA'\subseteq\cA$ with $\sum_{A\in\cA'}c(A)\leq B$.

\begin{theorem}[Khuller, Moss and Naor \cite{TheBudgetedMaximumCoverageProblem}]\label{thm:budgeted-maximum-coverage-source}
    There is a polynomial-time algorithm for budgeted Maximum Coverage that respects the budget and covers at least a $(1-1/e)$-fraction of the maximum number of elements coverable within that budget.
\end{theorem}

\begin{theorem}\label{thm:BPCSC-inforest}
    \setlength{\emergencystretch}{2em}
    There exist polynomial-time bicriteria $\br{1, \frac{e}{e-1}}$-approximation algorithms for $\ProblemBPCSC$ and $\ProblemPCSC$ when the precedence constraints form an inforest.
\end{theorem}
\begin{proof}
    We reduce $\ProblemBPCSC$ to budgeted Maximum Coverage and apply Theorem~\ref{thm:budgeted-maximum-coverage-source}.

    Given a $\ProblemBPCSC$ instance $(\cU,\cS,\preceq,b)$, set $\cX=\cU$ and $B=b$. For each $S\in\cS$, create an indexed set $z_S=\cov\br{\closure{S}}$ with cost $c(z_S)=\spr{\closure{S}}$.
    In an inforest, intersecting closures are nested: $\closure{S}\cap\closure{W}\neq\emptyset$ implies $S\preceq W$ or $W\preceq S$.
    Thus, from any selected family of the $z_S$, we can discard sets whose closures are contained in another selected closure without changing coverage or increasing cost. The remaining closures are disjoint, so their union is precedence-closed and has the same size and coverage as the cost and coverage of the retained family.
    Conversely, every precedence-closed family $\cC$ is the disjoint union of the closures of its maximal members. Selecting the corresponding $z_S$ therefore preserves both cost and coverage. The budgeted approximation follows, and Corollary~\ref{cor:BPCSC-to-PCSC} gives the result for $\ProblemPCSC$.
\end{proof}

Via a careful examination of Theorem~\ref{thm:BPCSC-to-PCMSSC}, we obtain the following result for $\ProblemPCMSSC$
\begin{corollary}\label{cor:BPCSC-inforest-to-PCMSSC}
    \setlength{\emergencystretch}{2em}
    There exists a bicriteria $\br{864\cdot\br{\frac{e}{e-1}}^3+1, \frac{e}{e-1}}\approx\br{3421.7, \frac{e}{e-1}}$-approximation polynomial-time algorithm for $\ProblemPCMSSC$ when the precedence constraints form an inforest.
\end{corollary}

\paraTitle{Steiner problems.}
Let $(V,d)$ denote a symmetric metric with distance function $d: V \times V \to \mathbb{R}_{\geq 0}$ satisfying the triangle inequality.
An \emph{$r$-tour} $\tau$ is a walk that starts and ends at $r \in V$. Denote by $\spr{\tau}$ the length of tour $\tau$ with respect to $d$.
Let $\cX$ be a family of \emph{groups}, where $X\subseteq V$ for each $X \in \cX$.
Let $w: \cX \to \mathbb{R}_{\geq 0}$ be a weight assignment to groups.
Let $\cov\br{\tau} \subseteq \cX$ denote the set of all groups \emph{covered} by tour $\tau$, that is, $\cov\br{\tau} = \brc{X \in \cX\colon X \cap \tau \neq \emptyset}$, where we slightly abuse notation and write $X \cap \tau$ for the intersection of $X$ with the set of vertices visited by $\tau$.
% For a tour $\tau$ and a group $X \in \cX$, define $t_\tau(X)$ as the length of the shortest prefix of $\tau$ (with respect to $d$) that visits at least one vertex from $X$. If $X \notin \cov\br{\tau}$, we set $t_\tau(X) = \spr{\tau}$.

\begin{problem}[\textsc{Group Steiner Orienteering} (GSO)] \label{problem:GSO}
Given a metric space $(V, d)$, a root vertex $r \in V$, a family of groups $\cX \subseteq 2^V$, a weight function $w: \cX \to \mathbb{R}_{\geq 0}$, and a budget $\budget > 0$, find an $r$-tour $\tau$ with $\spr{\tau} \leq \budget$ that maximizes
$\sum_{X \in \cov\br{\tau}} w(X)$.
\end{problem}
The following tree-metric guarantee follows from the algorithm and analysis in Section~5.1 of \cite{ApproxAlgsForOptDTsAndAdapTSPProblems}: for a tree metric, the tree-embedding step is unnecessary, saving a logarithmic factor.
\begin{theorem}[Gupta, Nagarajan and Ravi \cite{ApproxAlgsForOptDTsAndAdapTSPProblems}, Section~5.1]\label{thm:gso-tree-source}
    For a $\ProblemGSO$ instance on a tree metric $(V,d)$ with budget $\budget$, a polynomial-time algorithm finds an $r$-tour of length $\bigo\br{\log\spr{V}}\cdot\budget$ covering groups of total weight at least one quarter of the maximum weight coverable by an $r$-tour of length at most $\budget$.
\end{theorem}

\begin{theorem}\label{thm:BPCSC-outforest}
    \setlength{\emergencystretch}{2em}
    There exist polynomial-time bicriteria $\br{\bigo\br{\log m}, 4}$-approximation algorithms for $\ProblemBPCSC$,  $\ProblemPCSC$ and $\ProblemPCMSSC$ when the precedence constraints form an outforest.
\end{theorem}
\begin{proof}
    We reduce $\ProblemBPCSC$ to $\ProblemGSO$ on tree metrics and apply Theorem~\ref{thm:gso-tree-source}. Our tree has $\spr{V}=m+1$ vertices.
    
    We create a rooted tree as follows. Introduce a dummy root node $r$. For every minimal element $S$ of the outforest, connect $r$ to its representative $v_S$ by an edge of length~$1/2$. For every nonminimal element $W$, let $S$ be its unique immediate predecessor (parent), and connect $v_S$ to $v_W$ by an edge of length~$1/2$. Thus, the path from $r$ to $v_W$ visits all strict predecessors of $W$ before $v_W$. For each element $u\in\cU$, let $X_u=\brc{v_S \mid u\in S}$. For every distinct nonempty set $X$ among the $X_u$, include a GSO group $X$ with weight $w(X)=\spr{\brc{u\in\cU\mid X_u=X}}$.

    Expand each edge of an $r$-tour $\tau$ in the tree metric along its tree path, preserving its length and all groups it covers. For the resulting walk, let $\cC_\tau=\brc{S\in\cS\mid v_S\text{ is visited by }\tau}$. The root-to-vertex paths imply that $\cC_\tau$ is precedence-closed. The subtree formed by these paths has $\spr{\cC_\tau}$ edges, one for each visited representative. Since $\tau$ starts and ends at $r$, it traverses each edge in this subtree at least twice. As every edge has length~$1/2$, we have $\spr{\cC_\tau}\leq\spr{\tau}$. The total weight of groups covered by $\tau$ equals $\spr{\cov\br{\cC_\tau,\cU}}$.

    Conversely, for any precedence-closed family $\cC$, the union of the root-to-$v_S$ paths for $S\in\cC$ has $\spr{\cC}$ edges. A closed DFS walk traverses each edge twice, so its length is $2\cdot\frac12\cdot\spr{\cC}=\spr{\cC}$ and it covers groups of total weight $\spr{\cov\br{\cC,\cU}}$. Thus the reduction preserves the optimum coverage for each budget, and Corollary~\ref{cor:BPCSC-to-PCSC} and Theorem~\ref{thm:BPCSC-to-PCMSSC} imply the theorem.
\end{proof}
