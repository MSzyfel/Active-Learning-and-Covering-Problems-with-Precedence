\section{Set covering with precedence constraints} \label{sec:SC}

% Similarly as in previous section we assume our input instance to be unweighted. Note that the analysis of the following procedures works also in the weighted setting, where every element $u\in\cU$ has a weight $w(u)$ and the goal is to maximize the total weight of covered elements or cover at least a given total weight of elements with minimal size of the cover. Since this generalization is straightforward we omit it for clarity.

We obtain approximation guarantees for our covering tasks using the \textsc{Partial Red-Blue Set Cover} ($\ProblemPRBSC$) problem. We first give an algorithm for $\ProblemPRBSC$ and reduce $\ProblemPCSC$ to it. We then introduce a budgeted variant, obtain an approximation for it using $\ProblemPCSC$, and use it to approximate $\ProblemPCMSSC$. Although approximation algorithms for $\ProblemPRBSC$ are already known, we give an algorithm with an improved approximation ratio.

\begin{problem}[\textsc{Partial Red-Blue Set Cover} ($\ProblemPRBSC$)] \label{problem:PRBSC}
Given disjoint sets $\cR$ of $k$ red elements and $\cB$ of $n$ blue elements, a family $\cA$ of subsets of $\cR\cup\cB$, and an integer target $t$, choose a subfamily $\cA'\subseteq\cA$ that covers at least $t$ blue elements and minimizes \DDfix{the \emph{red cost}} $\spr{\cov\br{\cA',\cR}}$.
\end{problem}

\subsection{A bicriteria algorithm for Partial Red-Blue Set Cover}
\label{subsection:PRBSC-bicriteria}
Let $m$ be the number of input sets, $n=\spr{\cB}$ the number of blue elements, $k=\spr{\cR}$ the number of red elements, and $t$ the target number of blue elements to cover. Chlamt{\'{a}}{\v{c}}, Makarychev and Vakilian give a $\bigo\br{m^{1/3}\cdot \log^{4/3}k\cdot \log n}$-approximation for $\ProblemPRBSC$~\cite[Section~3 and Appendix~A]{RedBlueSetCover}. We first show that allowing a constant-factor loss in blue coverage (which is sufficient for our needs) improves this to a pure $\bigo\br{m^{1/3}}$ guarantee, and by repetition, a true $\bigo\br{m^{1/3}\cdot\log n}$-approximation.
%  Our deterministic algorithm covers at least one eighth of the target at cost $\bigo\br{m^{1/3}}$ times the optimum for target $t$.
Our algorithm builds on their LP-rounding approach, however we use a stronger LP relaxation. Moreover, our is more involved, including a non-trivial derandomization step. In the original algorithm, the sets are partitioned according to the number of red elements they contain and a step finding a collection with a favorable ratio of red cost to blue coverage is repeated until the target is met. We inherit this bucketing idea, however we round all these size groups together. In order to bound the cost of our solution we distinguish \emph{heavy} and \emph{light} covering sets according to the LP solution. Additional constraints for pairs of red elements allow us to bound the expected red cost of heavy sets across all sizes, while light sets have sufficiently small selection probabilities that we can bound their total cost by counting them with multiplicity. In order to show that our algorithm covers a significant fraction of the blue elements, we use random marks to identify some of the covered blue elements. Their randomized choice allows us to lower bound the expected number of distinct marked elements and, at the same time, upper bound this value's second moment. This comes in handy during the derandomization step where we design a carefully defined random variable we call \emph{potential}, whose non-negative value is maintained throughout the rounding using the method of conditional expectations, yielding a quality deterministic solution in polynomial time.

\begin{theorem}\label{thm:partial-red-blue-bicriteria}
There is a deterministic polynomial-time algorithm for $\ProblemPRBSC$ that outputs a subfamily $\cA'\subseteq\cA$ satisfying $\spr{\cov\br{\cA',\cB}}\geq t/8$ and $\spr{\cov\br{\cA',\cR}}\leq920\cdot m^{1/3}\cdot\OPT$, where $\OPT$ is the optimum red cost for target $t$.
\end{theorem}
\begin{proof}
Write $\cR_A=A\cap\cR$ and $\cB_A=A\cap\cB$ for each $A\in\cA$. 
% First select all sets $A$ with $\cR_A=\emptyset$, that is, all sets containing no red elements. If they cover at least $t/8$ blue elements, return this family. In particular, this handles every instance whose optimum red cost is zero. 
In the first step we guess an integer $K\in[\spr{\cR}]$ for the optimum red cost $\OPT$ (this can be done in $O\br{\log\br{\spr{\cR}}}$ tries). Assume that we have a correct guess. In our LP there will be the following variables:
\begin{enumerate}
    \item For each red element $r\in\cR$, the variable $y_r\in[0,1]$ indicating whether $r$ is covered.
    \item For each set $A\in\cA$, the variable $x_A\in[0,1]$ indicating whether $A$ is selected.
    \item For each blue element $u\in\cB$, the variable $z_u\in[0,1]$ indicating whether $u$ is one of the $t$ \emph{chosen} covered blue elements. An optimal integral solution may cover additional blue elements.
    \item For each $A\in\cA$ and $u\in\cB_A$, the variable $a_{u,A}\in[0,1]$ indicating the part of $z_u$ assigned to the set $A$. In an integral solution each chosen $u$  is assigned to one selected set containing it. 
    \item For each ordered pair $r,q\in\cR$, the variable $y_{r,q}\in[0,1]$ with intended integral value is $y_r\cdot y_q$. Note, that we will not impose this nonlinear equality, but use linear inequalities that it satisfies.
\end{enumerate}

For the current guess $K$, the LP is as follows
\begin{align}
 \sum_{r\in\cR}y_r&\leq K, \quad\quad \sum_{u\in\cB}z_u=t, && \label{eq:rbsc-lp-budget}\\
 \sum_{A\in\cA\colon u\in \cB_A}a_{u,A}&=z_u &&(u\in\cB), \label{eq:rbsc-lp-assign}\\
 a_{u,A}&\leq x_A &&(A\in\cA,\ u\in \cB_A), \label{eq:rbsc-lp-marginal}\\
 \sum_{u\in \cB_A}a_{u,A}&\leq t\cdot x_A &&(A\in\cA), \label{eq:rbsc-lp-set}\\
 x_A&\leq y_r &&(A\in\cA,\ r\in \cR_A), \label{eq:rbsc-lp-red}\\
 \sum_{A\in\cA\colon r\in \cR_A,\,u\in \cB_A}a_{u,A}&\leq y_r &&(r\in\cR,\ u\in\cB), \label{eq:rbsc-lp-blue-load}\\
 \sum_{A\in\cA\colon r\in \cR_A}\sum_{u\in \cB_A}a_{u,A}&\leq t\cdot y_r &&(r\in\cR), \label{eq:rbsc-lp-total-load}\\
 x_A&\leq y_{r,q} &&(A\in\cA,\ r,q\in \cR_A), \label{eq:rbsc-lp-pair}\\
 \sum_{q\in\cR}y_{r,q}&\leq K\cdot y_r &&(r\in\cR). \label{eq:rbsc-lp-pair-budget}
\end{align}
% The assignment constraints limit the load on each set and red element. In particular, they prevent the same blue element from contributing too much within a group and bound the total number of marks expected in an active group. The pair constraints give a budget for jointly covered red elements. This will let us charge heavy occurrences across all scales.
%  The following claim verifies the relaxation.

\begin{claim}\label{claim:rbsc-lp-validity}
For the correct guess $K=\OPT$, the above system is a polynomial-size relaxation of $\ProblemPRBSC$ with red-cost bound $\OPT$.
\end{claim}
\begin{proof}
Let $\cA^*\subseteq\cA$ be an optimal solution, with $\spr{\cov\br{\cA^*,\cB}}\geq t$ and $\spr{\cov\br{\cA^*,\cR}}=\OPT=K$. Choose $\cB^*\subseteq\cov\br{\cA^*,\cB}$ with $\spr{\cB^*}=t$ and, for each $u\in\cB^*$, choose a set $A_u\in\cA^*$ containing $u$. Define
\[
 x_A=\boldsymbol{1}_{A\in\cA^*},\qquad
 y_r=\boldsymbol{1}_{r\in\cov\br{\cA^*,\cR}},\qquad
 z_u=\boldsymbol{1}_{u\in\cB^*},\qquad
 y_{r,q}=y_r\cdot y_q.
\]
For the assignment variables, set $a_{u,A_u}=1$ for each $u\in\cB^*$ and set all other $a_{u,A}$ to zero.

The budget and assignment constraints hold by construction. Each assigned blue element belongs to a selected set, and at most $t$ blue elements are assigned to any set, proving~\eqref{eq:rbsc-lp-marginal} and~\eqref{eq:rbsc-lp-set}. \DDfix{Each selected set does not contain red elements that are not covered,} proving~\eqref{eq:rbsc-lp-red} and~\eqref{eq:rbsc-lp-pair}. If $y_r=0$, no selected set contains $r$, so both assignment sums in~\eqref{eq:rbsc-lp-blue-load} and~\eqref{eq:rbsc-lp-total-load} involving $r$ vanish. If $y_r=1$, a fixed blue element is assigned at most once, and there are $t$ assignments in total. This proves~\eqref{eq:rbsc-lp-blue-load} and~\eqref{eq:rbsc-lp-total-load}. Moreover,
\[
 \sum_{q\in\cR}y_{r,q}=y_r\cdot\sum_{q\in\cR}y_q=\OPT\cdot y_r=K\cdot y_r,
\]
which proves~\eqref{eq:rbsc-lp-pair-budget}. The numbers of variables and constraints are polynomial in the explicit input size. In particular, the guess $K=\OPT$ gives a feasible relaxation.
\end{proof}

For the smallest feasible guess $K\leq \OPT$ fix a feasible solution and put
\[
 T=m^{1/3},\qquad \cR_+=\brc{r\in\cR\colon y_r\geq1/T},\qquad \cR'_A=\cR_A\setminus \cR_+, \textup{ for }A\in\cA.
\]
We call $\cR'_A$ the \emph{residual red part} of $A$. By~\eqref{eq:rbsc-lp-budget}, $\spr{\cR_+}/T\leq\sum_{r\in \cR_+}y_r\leq K$, so $\spr{\cR_+}\leq K\cdot T$. Initially select the family $\cA_0=\brc{A\in\cA\colon \cR'_A=\emptyset}$. Its red coverage satisfies $\cov\br{\cA_0,\cR}\subseteq\cR_+$, and hence $\spr{\cov\br{\cA_0,\cR}}\leq K\cdot T$. If $\spr{\cov\br{\cA_0,\cB}}\geq t/8$, retain $\cA_0$ as the candidate. Otherwise, define $\cB'=\cB\setminus\cov\br{\cA_0,\cB}$. Then $\spr{\cB\setminus\cB'}=\spr{\cov\br{\cA_0,\cB}}<t/8$. Since $z_u\leq1$, we obtain
\begin{equation}\label{eq:rbsc-residual-mass}
 \sum_{u\in\cB'}z_u
 =t-\sum_{u\in\cB\setminus\cB'}z_u
 \geq t-\spr{\cB\setminus\cB'}>\frac{7}{8}\cdot t.
\end{equation}

For every power of two $s=2^j\leq\spr{\cR}$ with $j\in\mathbb{Z}_{\geq0}$, which we call a \emph{scale}, define $\cA_s$ and, for each $r\in\cR\setminus \cR_+$ with $y_r>0$, the \emph{group} $\cA_{r,s}$ by
\[
 \cA_s=\brc{A\in\cA\colon s\leq\spr{\cR'_A}<2\cdot s},
 \qquad
 \cA_{r,s}=\brc{A\in\cA_s\colon r\in \cR'_A}.
\]
Each set with a nonempty residual red part belongs to exactly one $\cA_s$. We call $r$ the \emph{pivot} of $\cA_{r,s}$. A set $A\in\cA_s$ belongs to the group $\cA_{r,s}$ for each residual red element $r\in\cR'_A$ with $y_r>0$. We call its membership in each such group an \emph{occurrence} of $A$. A set at scale $s$ has at least $s$ residual red elements and hence, unless its LP value is zero, at least $s$ occurrences. 
% This multiplicity will compensate for the factor $1/s$ in the activation probability.

For each $r$ and $s$, let $E_{r,s}$ be the event that group $\cA_{r,s}$ is \emph{activated}, with $\Pr[E_{r,s}]=y_r/s$. For each $A\in\cA_{r,s}$, let $J_{r,s,A}$ be the event that its \emph{trial} succeeds, with $\Pr[J_{r,s,A}]=x_A/y_r$. The activation and trial events are mutually independent, including across groups with the same members. An occurrence of $A$ is \emph{selected} if and only if both $E_{r,s}$ and $J_{r,s,A}$ occur, so selection events in the same group share the activation event. Note, that both probabilities belong to $[0,1]$ by~\eqref{eq:rbsc-lp-red} and $s\geq1$. Define the random families $\cF_{r,s}$ and $\cA'$, sets $\cR_{r,s}$ and $\cR_0$, and the variable $R$ by
\[
 \begin{gathered}
 \cF_{r,s}=\brc{A\in\cA_{r,s}\colon E_{r,s}\text{ and }J_{r,s,A}\text{ occur}},
 \qquad \cA'=\cA_0\cup\bigcup_{r,s}\cF_{r,s},\\
 \cR_{r,s}=\bigcup_{A\in\cF_{r,s}}\cR'_A,
 \qquad \cR_0=\bigcup_{r,s}\cR_{r,s},
 \qquad R=\spr{\cR_+}+\spr{\cR_0}.
 \end{gathered}
\]
The output satisfies $\cov\br{\cA',\cR}\subseteq\cR_+\cup\cR_0$, and therefore $\spr{\cov\br{\cA',\cR}}\leq R$.

\begin{claim}\label{claim:rbsc-red-cost}
The random construction satisfies $\mathbb{E}[R]\leq7\cdot K\cdot T$.
\end{claim}
\begin{proof}
Put $\theta=K/T$. We split occurrences according to their trial probabilities: heavy occurrences can be charged to the joint red variables, while light occurrences are cheap enough to count individually. For each group $\cA_{r,s}$, partition its occurrences into the \emph{heavy} and \emph{light} families
\[
 \cA^h_{r,s}=\brc{A\in\cA_{r,s}\colon x_A/y_r\geq\theta/s},
 \qquad \cA^\ell_{r,s}=\cA_{r,s}\setminus\cA^h_{r,s}.
\]
The same set may be heavy in one group and light in another. Define the random sets of residual red elements reached by selected heavy and light occurrences by
\[
 \cR_h=\bigcup_{r,s}\bigcup_{A\in\cF_{r,s}\cap\cA^h_{r,s}}\cR'_A,
 \qquad
 \cR_\ell=\bigcup_{r,s}\bigcup_{A\in\cF_{r,s}\cap\cA^\ell_{r,s}}\cR'_A.
\]
Define $R_h=\spr{\cR_h}$ and $R_\ell=\spr{\cR_\ell}$. Since every selected occurrence is either heavy or light, $R\leq\spr{\cR_+}+R_h+R_\ell$. We bound the expectations of these two variables separately.

Fix $r,q\in\cR\setminus\cR_+$ with $y_r>0$. Define $\cS_{r,q}=\brc{s\colon \exists A\in\cA^h_{r,s}\colon q\in\cR'_A}$ and the event
\[
 F_{r,q}=\bigcup_{s\in\cS_{r,q}}\ \bigcup_{A\in\cA^h_{r,s}\colon q\in\cR'_A}\br{E_{r,s}\cap J_{r,s,A}}.
\]
Thus, $F_{r,q}$ occurs when a selected heavy occurrence in a group $\cA_{r,s}$ contains $q$ in its residual red part. For all other ordered pairs $r,q\in\cR$, let $F_{r,q}$ be the empty event. If $\cS_{r,q}$ is empty, the event $F_{r,q}$ is impossible. Otherwise, for each $s\in\cS_{r,q}$, a corresponding heavy occurrence satisfies
\[
 y_{r,q}\geq x_A\geq\frac{\theta\cdot y_r}{s},
\]
where the first inequality follows from~\eqref{eq:rbsc-lp-pair}. In particular, $y_{r,q}>0$ and $s\geq\theta\cdot y_r/y_{r,q}$. Let $s_0$ be the smallest scale in $\cS_{r,q}$. All scales are powers of two, so every scale in $\cS_{r,q}$ is of the form $2^j\cdot s_0$ for some integer $j\geq0$. A selected occurrence requires its group to be active, so $F_{r,q}\subseteq\bigcup_{s\in\cS_{r,q}}E_{r,s}$. Applying the union bound and using the geometric series $\sum_{j\geq0}2^{-j}=2$ gives
\[
 \Pr[F_{r,q}]\leq\sum_{s\in\cS_{r,q}}\frac{y_r}{s}
 \leq\sum_{j\geq0}\frac{y_r}{2^j\cdot s_0}=\frac{2\cdot y_r}{s_0}
 \leq\frac{2\cdot y_{r,q}}{\theta}.
\]
The same bound holds when $\cS_{r,q}$ is empty, since $y_{r,q}\geq0$. If $q\in\cR_h$, then some selected heavy occurrence containing $q$ belongs to a group $\cA_{r,s}$, so $F_{r,q}$ occurs for its pivot $r$. Thus the union bound gives $\Pr[q\in\cR_h]\leq\sum_{r\in\cR}\Pr[F_{r,q}]$ for each $q\in\cR$. By linearity of expectation,
\[
 \mathbb{E}[R_h]
 =\sum_{q\in\cR}\Pr[q\in\cR_h]
 \leq\sum_{r\in\cR}\sum_{q\in\cR}\Pr[F_{r,q}]
 \leq\frac{2}{\theta}\cdot\sum_{r\in\cR}\sum_{q\in\cR}y_{r,q}
 \leq\frac{2\cdot K}{\theta}\cdot\sum_{r\in\cR}y_r
 \leq\frac{2\cdot K^2}{\theta}.
\]

Now, for each $A\in\cA^\ell_{r,s}$, independence of the activation and trial events give
\[
 \Pr[E_{r,s}\cap J_{r,s,A}]
 =\Pr[E_{r,s}]\cdot\Pr[J_{r,s,A}]
 =\frac{y_r}{s}\cdot\frac{x_A}{y_r}
 =\frac{x_A}{s}<\frac{\theta\cdot y_r}{s^2}.
\]
By linearity of expectation, the above probability bound and $y_r<1/T$,
\[
 \mathbb{E}[R_\ell]
 \leq\sum_{r,s}\sum_{A\in\cA^\ell_{r,s}}\spr{\cR'_A}\cdot\Pr[E_{r,s}\cap J_{r,s,A}]
 \leq\frac{\theta}{T}\cdot\sum_{r,s}\sum_{A\in\cA^\ell_{r,s}}\frac{\spr{\cR'_A}}{s^2}
 \leq\frac{\theta}{T}\cdot\sum_s\sum_{A\in\cA_s}\frac{\spr{\cR'_A}^2}{s^2}
 \leq\frac{4\cdot\theta\cdot m}{T}.
\]
Here, the third inequality counts, for each $A\in\cA_s$, at most one occurrence for each of its $\spr{\cR'_A}$ residual red elements. The last inequality uses $\spr{\cR'_A}/s<2$ and the fact that there are at most $m$ sets. Adding $\spr{\cR_+}\leq K\cdot T$ and substituting $\theta=K/T$ and $m=T^3$ gives
\begin{equation}\label{eq:rbsc-cost-expectation}
 \mathbb{E}[R]
 \leq K\cdot T+\frac{2\cdot K^2}{\theta}+\frac{4\cdot\theta\cdot m}{T}
 =3\cdot K\cdot T+\frac{4\cdot K\cdot m}{T^2}
 =7\cdot K\cdot T.
\end{equation}
\end{proof}

To control blue coverage, we use auxiliary \emph{marks} to identify some of the blue elements covered by selected occurrences. For each occurrence of $A$ with $x_A>0$ in group $\cA_{r,s}$, independently mark each $u\in\cB_A\cap\cB'$ using a coin $Z_{r,s,A,u}$ with $\Pr[Z_{r,s,A,u}=1]=a_{u,A}/x_A$. These marking choices are independent of all activations, trials, and other marking choices. The probabilities lie in $[0,1]$ by~\eqref{eq:rbsc-lp-marginal}. For $x_A=0$, take the coins to be always zero. The marking probability is chosen so that, combined with the trial probability, an occurrence contributes in proportion to its assignment mass $a_{u,A}$. Define $\cD_{r,s,A}=\brc{u\in\cB_A\cap\cB'\colon J_{r,s,A}\text{ occurs and }Z_{r,s,A,u}=1}$. Let $\cB_{r,s}=\bigcup_{A\in\cF_{r,s}}\cD_{r,s,A}$ be the set of elements marked by selected occurrences in group $\cA_{r,s}$ and $\widehat{\cB}=\bigcup_{r,s}\cB_{r,s}$ with $Y=\spr{\widehat{\cB}}$. 
% In an active group, a successful trial with no marks still selects the occurrence and its red elements.

\begin{claim}\label{claim:rbsc-blue-coverage}
The expected number of distinct marked blue elements satisfies $\mathbb{E}[Y]>2\cdot t/5$.
\end{claim}
\begin{proof}
Fix $u\in\cB'$. For an occurrence of $A$ in group $\cA_{r,s}$ with $u\in \cB_A$ and $x_A>0$, the probability that its trial succeeds and its marking coin for $u$ succeeds is
\[
 \Pr[u\in \cD_{r,s,A}]=\frac{x_A}{y_r}\cdot\frac{a_{u,A}}{x_A}=\frac{a_{u,A}}{y_r}.
\]
When $x_A=0$, $\Pr[u\in \cD_{r,s,A}]=a_{u,A}=0$. The sum of these probabilities within $\cA_{r,s}$ is
\[
 \lambda_{r,s,u}
 =\sum_{A\in\cA_{r,s}\colon u\in\cB_A}\Pr[u\in\cD_{r,s,A}]
 =\frac1{y_r}\cdot\sum_{A\in\cA_{r,s}\colon u\in \cB_A}a_{u,A}
 \leq1
\]
by~\eqref{eq:rbsc-lp-blue-load}. The choices for the set occurrences are independent. We use the inequality $1-x\leq e^{-x}$ and the concavity of $1-e^{-a\cdot x}$, which gives $1-e^{-a\cdot x}\geq(1-e^{-a})\cdot x$ for $a\geq0$ and $x\in[0,1]$. The group's conditional probability of marking $u$ is therefore at least
\[
 \Pr[u\in\cB_{r,s}\mid E_{r,s}]
 =1-\prod_{A\in\cA_{r,s}\colon u\in \cB_A}
       \br{1-\frac{a_{u,A}}{y_r}}
 \geq1-e^{-\lambda_{r,s,u}}
 \geq(1-e^{-1})\cdot\lambda_{r,s,u}.
\]
Since $\cB_{r,s}=\emptyset$ when the group is inactive, the preceding bound and the definition of $\lambda_{r,s,u}$ give
\[
 \Pr[u\in\cB_{r,s}]=\Pr[E_{r,s}]\cdot\Pr[u\in\cB_{r,s}\mid E_{r,s}]
 \geq\frac{y_r}{s}\cdot(1-e^{-1})\cdot\lambda_{r,s,u}
 =\frac{1-e^{-1}}{s}\cdot\sum_{A\in\cA_{r,s}\colon u\in \cB_A}a_{u,A}.
\]
Let $M_u=\sum_{r,s}\boldsymbol{1}_{u\in\cB_{r,s}}$ be the number of groups that mark $u$. By linearity of expectation and the group bound above,
\begin{align*}
 \mathbb{E}[M_u]&=\sum_{r,s}\Pr[u\in\cB_{r,s}]
 \geq(1-e^{-1})\cdot\sum_{r,s}\frac1s\cdot
       \sum_{A\in\cA_{r,s}\colon u\in \cB_A}a_{u,A}\\
 &=(1-e^{-1})\cdot\sum_s\sum_{A\in\cA_s\colon u\in \cB_A}
       \frac{a_{u,A}}s\cdot\sum_{r\in\cR'_A\colon y_r>0}1\\
 &=(1-e^{-1})\cdot\sum_s\sum_{A\in\cA_s\colon u\in \cB_A}
       \frac{\spr{\cR'_A}}s\cdot a_{u,A}
 \geq(1-e^{-1})\cdot\sum_{A\in\cA\colon u\in \cB_A}a_{u,A}
 =(1-e^{-1})\cdot z_u.
\end{align*}
For the second equality, fix a scale $s$ and a set $A_u\in\cA_s$ containing $u$. The term $a_{u,A_u}$ appears in $\sum_r\sum_{A'\in\cA_{r,s}\colon u\in\cB_{A'}}a_{u,A'}$ once for each $r\in\cR'_A$ with $y_r>0$. If $y_r=0$ for some $r\in\cR'_A$, then $a_{u,A_u}\leq x_{A_u}\leq y_r=0$ by~\eqref{eq:rbsc-lp-marginal} and~\eqref{eq:rbsc-lp-red}, so these pivots can also be counted. For the last inequality, every set $A$ containing $u\in\cB'$ has nonempty $\cR'_A$. Otherwise, $A\in\cA_0$ and would cover $u$. Such a set belongs to exactly one scale $s$, where $\spr{\cR'_A}/s\geq1$. Since $a_{u,A}\geq0$, replacing this factor by $1$ gives the lower bound.

The rounding choices for distinct group indices are independent. Applying $1-x\leq e^{-x}$ across groups and then the above concavity bound for $z_u\in[0,1]$ yields
\[
 \Pr[u\in\widehat{\cB}]
 =1-\prod_{r,s}\br{1-\Pr[u\in\cB_{r,s}]}
 \geq1-e^{-\mathbb{E}[M_u]}
 \geq1-e^{-(1-e^{-1})\cdot z_u}
 \geq c\cdot z_u,
 \qquad c=1-e^{-(1-e^{-1})}.
\]
Since $c>23/50$, summing over $\cB'$ and using~\eqref{eq:rbsc-residual-mass} gives
\[
 \mathbb{E}[Y]=\sum_{u\in\cB'}\Pr[u\in\widehat{\cB}]\geq c\cdot\sum_{u\in\cB'}z_u
 >\frac{23}{50}\cdot\frac{7\cdot t}{8}
 =\frac{161\cdot t}{400}>\frac{2\cdot t}{5}.
\]
\end{proof}

For each group $\cA_{r,s}$, define
\[
 L_{r,s}=\sum_{A\in\cA_{r,s}}\spr{\cD_{r,s,A}},
 \qquad W_{r,s}=\boldsymbol{1}_{E_{r,s}}\cdot L_{r,s},
 \qquad W=\sum_{r,s}W_{r,s}.
\]
Thus $W_{r,s}$ counts the marks in group $\cA_{r,s}$ with multiplicity over its selected occurrences. A blue element marked by two occurrences is counted twice in $W$, even if the occurrences are in the same group. In particular, $Y\leq W$.

\begin{claim}\label{claim:rbsc-second-moment}
We have $\mathbb{E}[W^2]\leq10\cdot t^2$.
\end{claim}
\begin{proof}
Fix a group $\cA_{r,s}$. For each occurrence $A\in\cA_{r,s}$, let $X_A=\spr{\cD_{r,s,A}}$, so $L_{r,s}=\sum_{A\in\cA_{r,s}}X_A$. These variables are defined before activation and are independent across occurrences. By linearity of expectation and the marking probabilities calculated above,
\[
 \mathbb{E}[X_A]=\sum_{u\in\cB_A\cap\cB'}\Pr[u\in\cD_{r,s,A}]
 =\frac1{y_r}\cdot\sum_{u\in \cB_A\cap\cB'}a_{u,A}.
\]
For the second moment, put $p_{u,A}=\Pr[Z_{r,s,A,u}=1]$ and $d_A=\sum_{u\in\cB_A\cap\cB'}p_{u,A}$. Let $N_A=\sum_{u\in\cB_A\cap\cB'}Z_{r,s,A,u}$. By~\eqref{eq:rbsc-lp-set}, $d_A\leq t$. The marking coins are independent Bernoulli variables, so
\[
 \mathbb{E}[N_A]=d_A,\qquad
 \operatorname{Var}(N_A)=\sum_{u\in\cB_A\cap\cB'}p_{u,A}\cdot(1-p_{u,A}).
\]
Moreover, $X_A=\boldsymbol{1}_{J_{r,s,A}}\cdot N_A$ and the trial is independent of $N_A$, so $\mathbb{E}[X_A]=(x_A/y_r)\cdot d_A$. Using $\mathbb{E}[N_A^2]=\mathbb{E}[N_A]^2+\operatorname{Var}(N_A)$ gives
\[
 \mathbb{E}[X_A^2]=\frac{x_A}{y_r}\cdot\br{d_A^2+\sum_{u\in\cB_A\cap\cB'}p_{u,A}\cdot(1-p_{u,A})}
 \leq\frac{x_A}{y_r}\cdot(d_A^2+d_A)
 \leq(t+1)\cdot\mathbb{E}[X_A].
\]
The first-moment calculation and $r\in\cR_A$ for every $A\in\cA_{r,s}$ give
\[
 \mathbb{E}[L_{r,s}]=\frac1{y_r}\cdot\sum_{A\in\cA_{r,s}}\sum_{u\in\cB_A\cap\cB'}a_{u,A}
 \leq\frac1{y_r}\cdot\sum_{A\in\cA\colon r\in\cR_A}\sum_{u\in\cB_A}a_{u,A}\leq t,
\]
where the last inequality follows from~\eqref{eq:rbsc-lp-total-load}. Expanding $L_{r,s}^2$ and using independence across distinct occurrences gives
\begin{align*}
 \mathbb{E}[L_{r,s}^2]
 &=\sum_{A\in\cA_{r,s}}\mathbb{E}[X_A^2]+\sum_{A,A'\in\cA_{r,s}\colon A\ne A'}\mathbb{E}[X_A]\cdot\mathbb{E}[X_{A'}]\\
 &\leq(t+1)\cdot\sum_{A\in\cA_{r,s}}\mathbb{E}[X_A]+\br{\sum_{A\in\cA_{r,s}}\mathbb{E}[X_A]}^2
 =(t+1)\cdot\mathbb{E}[L_{r,s}]+\mathbb{E}[L_{r,s}]^2\leq(2t+1)\cdot\mathbb{E}[L_{r,s}].
\end{align*}
The first inequality uses the bound on $\mathbb{E}[X_A^2]$ and adds the nonnegative terms with $A=A'$ to the cross terms. The last inequality uses $\mathbb{E}[L_{r,s}]\leq t$.
The variable $L_{r,s}$ is independent of activation. Multiplying the last bound by $y_r/s$ therefore gives
\begin{equation}\label{eq:rbsc-group-second-moment}
 \mathbb{E}[W_{r,s}^2]\leq(2t+1)\cdot\mathbb{E}[W_{r,s}].
\end{equation}
Moreover, by linearity of expectation, independence of $E_{r,s}$ and $L_{r,s}$, and the first-moment calculation above,
\begingroup\small
\begin{align*}
 \mathbb{E}[W]
 &=\sum_{r,s}\Pr[E_{r,s}]\cdot\mathbb{E}[L_{r,s}]
 =\sum_{r,s}\frac1s\cdot\sum_{A\in\cA_{r,s}}
       \sum_{u\in\cB_A\cap\cB'}a_{u,A}
 =\sum_s\sum_{A\in\cA_s}\frac1s\cdot
       \br{\sum_{r\in\cR'_A\colon y_r>0}1}\cdot\sum_{u\in\cB_A\cap\cB'}a_{u,A}\\
 &=\sum_s\sum_{A\in\cA_s}\frac{\spr{\cR'_A}}s\cdot
       \sum_{u\in\cB_A\cap\cB'}a_{u,A}
 \leq2\cdot\sum_{u\in\cB'}\sum_{A\in\cA\colon u\in\cB_A}a_{u,A}
 =2\cdot\sum_{u\in\cB'}z_u\leq2\cdot t.
\end{align*}
\endgroup
To justify the fourth equality, fix $A\in\cA_s$. If $y_r>0$ for every $r\in\cR'_A$, then the number of terms in the preceding sum over $r$ is $\spr{\cR'_A}$. Otherwise, some $r\in\cR'_A$ has $y_r=0$, and~\eqref{eq:rbsc-lp-marginal} and~\eqref{eq:rbsc-lp-red} imply $0\leq a_{u,A}\leq x_A\leq y_r=0$ for every $u\in\cB_A$. The assignment sum for $A$ therefore vanishes, so both terms are zero. The first inequality uses $\spr{\cR'_A}/s<2$ and extends the sum to all sets using nonnegativity of the assignment variables. The fifth equality follows from~\eqref{eq:rbsc-lp-assign}, and the second inequality follows from~\eqref{eq:rbsc-lp-budget} and $z_u\geq0$. Finally, independence of the rounding choices for distinct group indices and~\eqref{eq:rbsc-group-second-moment} imply
\[
 \mathbb{E}[W^2]
 =\sum_{r,s}\mathbb{E}[W_{r,s}^2]
   +\sum_{r,s}\sum_{\substack{r',s'\\(r',s')\ne(r,s)}}\mathbb{E}[W_{r,s}]\cdot\mathbb{E}[W_{r',s'}]
 \leq(2t+1)\cdot\mathbb{E}[W]+\br{\mathbb{E}[W]}^2
 \leq8\cdot t^2+2\cdot t\leq10\cdot t^2.
\]
which gives the proof of the claim.
\end{proof}

To find an outcome with both sufficient coverage and small red cost, we define a \emph{potential}
\begin{equation}\label{eq:rbsc-potential}
 \Phi=Y-\frac{W^2}{72\cdot t}-\frac{7\cdot t\cdot R}{360\cdot K\cdot T}-\frac{t}{8}.
\end{equation}
to be an affine combination of the random variables $Y$, $W^2$, and $R$. The term involving $Y$ rewards blue coverage, while the term involving $R$ penalizes red cost. Without the quadratic penalty, a large coverage reward could offset an arbitrarily large red cost. Since $W\geq Y$, the quadratic penalty grows faster than the coverage reward and prevents this from happening. At the same time, our bound on the second moment of $W$ ensures that the penalty is small enough on average to keep the expected potential nonnegative. An outcome with nonnegative potential then guarantees both sufficient coverage and a small red cost.
\begin{claim}\label{claim:rbsc-positive-potential}
We have $\mathbb{E}[\Phi]\geq0$. Every output $\cA'$ obtained from an outcome with $\Phi\geq0$ satisfies
\[
 \spr{\cov\br{\cA',\cB}}\geq t/8
 \qquad\text{and}\qquad
 \spr{\cov\br{\cA',\cR}}<920\cdot K\cdot T.
\]
In particular, for the correct guess $K=\OPT$, the red cost is smaller than $920\cdot\OPT\cdot T$.
\end{claim}
\begin{proof}
Claims~\ref{claim:rbsc-red-cost}, \ref{claim:rbsc-blue-coverage}, and~\ref{claim:rbsc-second-moment} give
\[
 \mathbb{E}[\Phi]
 >\frac{2\cdot t}{5}-\frac{10\cdot t^2}{72\cdot t}-\frac{7\cdot t\cdot7\cdot K\cdot T}{360\cdot K\cdot T}-\frac{t}{8}
 =0.
\]
If $\Phi\geq0$, all three subtracted terms are nonnegative, so $Y\geq t/8$. Since $\widehat{\cB}\subseteq\cov\br{\cA',\cB}$, we have $\spr{\cov\br{\cA',\cB}}\geq Y\geq t/8$. Furthermore, $W\geq Y$ implies
\[
 \frac{7\cdot t\cdot R}{360\cdot K\cdot T}
 \leq Y-\frac{W^2}{72\cdot t}-\frac{t}{8}
 \leq Y-\frac{Y^2}{72\cdot t}-\frac{t}{8}
 =18\cdot t-\frac{(Y-36\cdot t)^2}{72\cdot t}-\frac{t}{8}
 \leq\frac{143\cdot t}{8}.
\]
It follows that $\spr{\cov\br{\cA',\cR}}\leq R\leq\frac{6435}{7}\cdot K\cdot T<920\cdot K\cdot T$.
\end{proof}

Using the method of conditional expectations applied to the potential $\Phi$ in a relatively straightforward manner, allows us to derandomize our procedure as follows.

\begin{claim}\label{claim:rbsc-conditional-expectations}
An outcome with $\Phi\geq0$ can be found deterministically in polynomial time.
\end{claim}
\begin{proof}
In order to obtain a deterministic algorithm, instead of drawing the coins randomly, we process the groups in an arbitrary order, first fixing their activation, and then, for an active group, fixing each occurrence's trial and, if it succeeds, its marking coins. At each step we choose a possible value maximizing the conditional expectation of $\Phi$.
Fix a history of exposed coins, and let $\mathcal{E}$ be the event that they take their recorded values. Since $\mathcal{E}$ is an intersection of individual coin outcomes, all unfixed coins remain independent. The conditional probability that a coin succeeds is its original probability if it is unfixed, and $0$ or $1$ otherwise.

For $A\in\cA_{r,s}$ and $u\in\cB_A\cap\cB'$, independence conditional on $\mathcal{E}$ gives
\[
 \Pr[u\in\cD_{r,s,A}\mid\mathcal{E}]
 =\Pr[J_{r,s,A}\mid\mathcal{E}]\cdot\Pr[Z_{r,s,A,u}=1\mid\mathcal{E}].
\]
For $u\in\cB'$ and $q\in\cR\setminus\cR_+$, the probabilities that the group misses a blue or red element are
\[
 \begin{aligned}
 \Pr[u\notin\cB_{r,s}\mid\mathcal{E}]
 &=1-\Pr[E_{r,s}\mid\mathcal{E}]+\Pr[E_{r,s}\mid\mathcal{E}]\cdot\prod_{A\in\cA_{r,s}\colon u\in\cB_A}\br{1-\Pr[u\in\cD_{r,s,A}\mid\mathcal{E}]},\\
 \Pr[q\notin\cR_{r,s}\mid\mathcal{E}]
 &=1-\Pr[E_{r,s}\mid\mathcal{E}]+\Pr[E_{r,s}\mid\mathcal{E}]\cdot\prod_{A\in\cA_{r,s}\colon q\in\cR'_A}\br{1-\Pr[J_{r,s,A}\mid\mathcal{E}]}.
 \end{aligned}
\]
Independence of distinct groups and linearity of expectation then give
\begingroup\small
\begin{equation}\label{eq:rbsc-conditional-coverage-cost}
 \mathbb{E}[Y\mid\mathcal{E}]
 =\sum_{u\in\cB'}\br{1-\prod_{r,s}\Pr[u\notin\cB_{r,s}\mid\mathcal{E}]},\quad
 \mathbb{E}[R\mid\mathcal{E}]
 =\spr{\cR_+}+\sum_{q\in\cR\setminus \cR_+}\br{1-\prod_{r,s}\Pr[q\notin\cR_{r,s}\mid\mathcal{E}]}.
\end{equation}
\endgroup
For the second moment, fix a group $\cA_{r,s}$ and use the variables $N_A$ and $X_A$ defined in the proof of Claim~\ref{claim:rbsc-second-moment}. Conditional on $\mathcal{E}$, the marking coins and trial remain independent, so
\[
 \begin{gathered}
 \mathbb{E}[N_A\mid\mathcal{E}]=\sum_{u\in\cB_A\cap\cB'}\Pr[Z_{r,s,A,u}=1\mid\mathcal{E}],\qquad
 \mathbb{E}[X_A\mid\mathcal{E}]=\Pr[J_{r,s,A}\mid\mathcal{E}]\cdot\mathbb{E}[N_A\mid\mathcal{E}],\\
 \mathbb{E}[X_A^2\mid\mathcal{E}]=\Pr[J_{r,s,A}\mid\mathcal{E}]\cdot\br{\mathbb{E}[N_A\mid\mathcal{E}]^2+\sum_{u\in\cB_A\cap\cB'}\Pr[Z_{r,s,A,u}=1\mid\mathcal{E}]\cdot\br{1-\Pr[Z_{r,s,A,u}=1\mid\mathcal{E}]}}.
 \end{gathered}
\]
The variables $X_A$ remain independent across occurrences, and $L_{r,s}$ remains independent of activation. Thus
\[
 \begin{gathered}
 \mathbb{E}[L_{r,s}\mid\mathcal{E}]=\sum_{A\in\cA_{r,s}}\mathbb{E}[X_A\mid\mathcal{E}],\qquad
 \mathbb{E}[L_{r,s}^2\mid\mathcal{E}]=\mathbb{E}[L_{r,s}\mid\mathcal{E}]^2+\sum_{A\in\cA_{r,s}}\br{\mathbb{E}[X_A^2\mid\mathcal{E}]-\mathbb{E}[X_A\mid\mathcal{E}]^2},\\
 \mathbb{E}[W_{r,s}\mid\mathcal{E}]=\Pr[E_{r,s}\mid\mathcal{E}]\cdot\mathbb{E}[L_{r,s}\mid\mathcal{E}],\qquad
 \mathbb{E}[W_{r,s}^2\mid\mathcal{E}]=\Pr[E_{r,s}\mid\mathcal{E}]\cdot\mathbb{E}[L_{r,s}^2\mid\mathcal{E}].
 \end{gathered}
\]
Conditional on $\mathcal{E}$, the unfixed coins remain independent, and each $W_{r,s}$ depends only on coins belonging to its own group. Hence the variables $W_{r,s}$ are conditionally independent, and
\begin{equation}\label{eq:rbsc-conditional-second-moment}
 \mathbb{E}[W^2\mid\mathcal{E}]
 =\br{\sum_{r,s}\mathbb{E}[W_{r,s}\mid\mathcal{E}]}^2
  +\sum_{r,s}\br{\mathbb{E}[W_{r,s}^2\mid\mathcal{E}]-\mathbb{E}[W_{r,s}\mid\mathcal{E}]^2}.
\end{equation}
Substituting~\eqref{eq:rbsc-conditional-coverage-cost} and~\eqref{eq:rbsc-conditional-second-moment} into~\eqref{eq:rbsc-potential} computes $\mathbb{E}[\Phi\mid\mathcal{E}]$ in polynomial time. 
% The same formulas compute the conditional expectation for each possible value of the next coin. 
By averaging, one such value does not decrease the conditional expectation. There are polynomially many coins, so fixing them as above preserves the nonnegative initial expectation from Claim~\ref{claim:rbsc-positive-potential} in polynomial time.
\end{proof}

For the smallest feasible guess $K$, return $\cA'=\cA_0$ if $\spr{\cov\br{\cA_0,\cB}}\geq t/8$. Otherwise, use Claim~\ref{claim:rbsc-conditional-expectations} to obtain a solution $\cA'$ with nonnegative potential. In both cases, $\spr{\cov\br{\cA',\cB}}\geq t/8$ and $\spr{\cov\br{\cA',\cR}}\leq920\cdot K\cdot T$. Since $K=\OPT$ is feasible by Claim~\ref{claim:rbsc-lp-validity}, the smallest feasible guess satisfies $K\leq\OPT$. Therefore, $\spr{\cov\br{\cA',\cR}}\leq920\cdot\OPT\cdot T = \bigo\br{m^{1/3}}\cdot \OPT$ as promised.
\end{proof}

Repeating Theorem~\ref{thm:partial-red-blue-bicriteria} logarithmically many times on the remaining blue target yields an approximation that meets the full target. The original optimum remains feasible for the residual target in each iteration, so the red cost in each iteration is bounded in terms of the original optimum.
\begin{corollary}\label{cor:partial-red-blue}
    There is an $\bigo\br{m^{1/3}\cdot\log n}$-approximation algorithm for $\ProblemPRBSC$ running in polynomial time.
\end{corollary}

\subsection{\texorpdfstring{$\ProblemPCSC$}{PCSC} via Partial Red-Blue Set Cover}
\label{subsection:PCSC}
We now reduce $\ProblemPCSC$ to $\ProblemPRBSC$.
Given a precedence-constrained set covering instance $(\cU,\cS,\preceq)$, create a red element $r_S$ for each $S\in\cS$ and a blue element $b_u$ for each $u\in\cU$. For each $S\in\cS$, let $S^{+}=\closure{S}$ and create a red-blue set $A_S=\brc{r_T\colon T\in S^{+}}\cup\brc{b_u\colon u\in\cov\br{S^{+}}}$.
The resulting red-blue instance has $m$ sets and $n$ blue elements. For any selected subfamily indexed by $\mathcal{J}\subseteq\cS$, define a precedence-closed family $\cC_{\mathcal{J}}=\bigcup_{S\in\mathcal{J}}S^{+}$.
The red elements covered by the selected red-blue sets form $\brc{r_T\colon T\in\cC_{\mathcal{J}}}$, and the blue elements covered form $\brc{b_u\colon u\in\cov\br{\cC_{\mathcal{J}}}}$.
Thus, the red cost and blue coverage equal the size and coverage of $\cC_{\mathcal{J}}$, respectively.
Conversely, for any precedence-closed family $\cC\subseteq\cS$, selecting $A_S$ for every $S\in\cC$ covers the red elements corresponding to $\cC$ and the blue elements corresponding to $\cov\br{\cC}$, and no others: each $S^{+}\subseteq\cC$, and every $S\in\cC$ belongs to $S^{+}$. Hence, the reduction preserves cost and coverage in both directions.

\begin{theorem}\label{thm:PCSC-RBSC}
There are a polynomial-time approximation algorithms for $\ProblemPCSC$ with ratios $\bigo\br{m^{1/3}\cdot\log n}$ and $\br{\bigo\br{m^{1/3}},8}$.
\end{theorem}
\begin{proof}
Apply the reduction above with $t=\cl{f\cdot n}$, followed by either Corollary~\ref{cor:partial-red-blue} or Theorem~\ref{thm:partial-red-blue-bicriteria}. Since the reduction preserves cost and coverage, the theorem follows.
\end{proof}

\begin{corollary}\label{cor:bicriteria-decision-trees}
There is an $\bigo\br{m^{1/3}\cdot\log n}$-approximation algorithm for $\ProblemPCWCDT$ running in polynomial-time.
\end{corollary}
\begin{proof}
Combine Theorem~\ref{thm:PCSC-RBSC} with Theorem~\ref{thm:PCSC-to-PCWCDT}.
\end{proof}


\subsection{\texorpdfstring{$\ProblemPCMSSC$ via $\ProblemBPCSC$}{PCMSSC via B-PCSC}} \label{subsection:PCMSSC}
We introduce a budgeted variant of precedence-constrained set cover.
\begin{problem}[\textsc{Budgeted Precedence Constrained Set Cover} ($\ProblemBPCSC$)] \label{problem:BPCSC}
Given a universe $\cU$ of items, a family $\cS$ of subsets of $\cU$, a precedence relation $(\cS,\preceq)$ and a budget $\budget>0$, find a precedence-closed set $\cC\subseteq\cS$ that maximises $\spr{\cov\br{\cC,\cU}}$ and satisfies $\spr{\cC}\leq \budget$.
\end{problem}

An approximation for $\ProblemPCSC$ gives the same bicriteria guarantee for $\ProblemBPCSC$ by guessing the fraction of elements covered by an optimal budgeted solution.
\begin{theorem}\label{thm:PCSC-to-BPCSC}\label{thm:BPCSC}
If there is a polynomial-time $\br{\alpha,\beta}$-approximation algorithm for $\ProblemPCSC$, then there is a polynomial-time $\br{\alpha,\beta}$-approximation algorithm for $\ProblemBPCSC$. In particular, there approximations are $\br{\bigo\br{m^{1/3}\cdot\log n},1}$ and $\br{\bigo\br{m^{1/3}},8}$.
\end{theorem}
\begin{proof}
For each integer $t\in[\spr{\cov\br{\cS,\cU}}]$, run the $\ProblemPCSC$ algorithm with target fraction $f=t/n$. Among the resulting families of size at most $\alpha\cdot\budget$ and the empty family, return one with maximum coverage.
Let $\cCopt$ be an optimal solution to $\ProblemBPCSC$ and put $t^*=\spr{\cov\br{\cCopt,\cU}}$. If $t^*=0$, the empty family suffices. Otherwise, $\cCopt$ is feasible for $\ProblemPCSC$ with target fraction $f^*=t^*/n$, so the corresponding optimum is at most $\budget$. For the guess $t=t^*$, the algorithm therefore obtains a family of size at most $\alpha\cdot\budget$ covering at least $t^*/\beta$ elements.
\end{proof}

We show how to use an $(\alpha,\beta)$-approximation algorithm for $\ProblemBPCSC$ to obtain an $\br{\bigo\br{\alpha\cdot\beta^3}, \beta}$-approximation for $\ProblemPCMSSC$.  Our approach is reminiscent of the ideas used for solving problems regarding \textsc{Minimum Latency TSP}~\cite{PathsTreesMinimumLatencyTours,KTravelingRepairmenProblem} and \textsc{Adaptive TSP}~\cite{ApproxAlgsForOptDTsAndAdapTSPProblems}. The overarching theme of this connection is that one can treat appending sets to the covering sequence as a kind of tour on a DAG induced by the precedence constraints, and the cost of covering an element as a latency of `visiting' that element. This intuition is not exact and is not used directly in the procedure or its analysis.

Let $\alpha,\beta\geq 1$ and $a=\frac{3\cdot\beta-1}{3\cdot\beta-2}$, so $1<a\leq 2$.
% Denote by $\cCopt$ any optimal solution to $\ProblemPCMSSC$ on the input $(\cU, \cS, \preceq, f)$.
Let $l^*=\max\brc{1,\cl{\log_a\spr{\cCopt}}}$, where $\cCopt$ is an optimal solution to $\ProblemPCMSSC$.
So, $a^{l^*-1}\leq\spr{\cCopt}\leq a^{l^*}$.
We start with pseudocode for $\ProblemPCMSSC$ in Algorithm~\ref{alg:fPCMSSC}.
\input{pseudocodes/f_PCMSSC.tex}
Each family returned by $\ProblemBPCSC$ is precedence-closed, so the family $P_l$ of sets already appended is also precedence-closed. When a family is appended, only sets outside $P_l$ are used and they are ordered by $\operatorname{ord}$. Every predecessor of a new set is therefore either already in the sequence or earlier in the appended block. The same holds for the padding and the final family, so every sequence considered by the algorithm is precedence-closed and contains no repeated sets. In the analysis, $\pi_l$ denotes the padded prefix before the final family is appended.
We start with a lemma that relates the coverage times and the lengths of $\pi_{l^*}$ and $\cCopt$.
    \begin{lemma}\label{lem:pi-spread-cost}
        We have that $\spr{\pi_{l^*}} = \bigo\br{\alpha \cdot \beta}\cdot \spr{\cCopt}$, and if $\spr{\pi_{l^*}}<m$, then $\spr{\pi_{l^*}}=\Omega\br{\alpha\cdot\beta}\cdot\spr{\cCopt}$. Moreover, $\coverageTime\br{\pi_{l^*},\cU} = \bigo\br{\alpha\cdot\beta^3}\cdot \coverageTime\br{\cCopt,\cU}$.
    \end{lemma}
    \begin{proof}
        We observe that since we used an $\br{\alpha, \beta}$-approximation algorithm for $\ProblemBPCSC$ in each iteration of the inner for loop, we have that for each $1\leq i\leq l^*$, $\spr{\tau_{l^*}^i} \leq \alpha \cdot a^{i+1}$. Thus, the length after padding satisfies:
        \begin{equation} \label{eq:pi}
        \spr{\pi_{l^*}} \leq \max\brc{\alpha\cdot \sum_{i=1}^{l^*} a^{i+1},\min\brc{m,\cl{\alpha\cdot\beta\cdot a^{l^*}}}}\leq \frac{\alpha\cdot a^{l^*+3}}{a-1}\leq \frac{\alpha\cdot a^{4}}{a-1}\cdot\spr{\cCopt}=\bigo\br{\alpha\cdot\beta}\cdot\spr{\cCopt}.
        \end{equation}
        Here we used $\cl{x}\leq x+1$, $\alpha\cdot a^{l^*}\geq1$, $\beta\leq1/(a-1)$, and $a^{l^*}\leq a\cdot\spr{\cCopt}$. If $\spr{\pi_{l^*}}<m$, the padding target is not capped by $m$, and hence $\spr{\pi_{l^*}}\geq\alpha\cdot\beta\cdot a^{l^*}\geq\alpha\cdot\beta\cdot\spr{\cCopt}$. If $\spr{\pi_{l^*}}=m$, then the prefix contains every set in $\cS$. This case will be handled after the latency bound.

        For every $i\in [l^*]$, let $\ell_i=\min\brc{\spr{\cCopt},\fl{a^i}}$ and $n_i^*=\spr{\cov\br{\pref{\cCopt}{\ell_i}}}$, so $n_{l^*}^* = \spr{\cov\br{\cCopt}}$. Let $n_i=\spr{\cov\br{\bigcup_{j=1}^{i}\tau_{l^*}^j}}$ and $n_0=n_0^*=0$. We have:
        \begin{align*}
            &\coverageTime\br{\pi_{l^*},\cU}\leq \sum_{i=1}^{l^*}\br{n_i-n_{i-1}}\cdot \sum_{j=1}^{i}\alpha\cdot a^{j+1} + \br{n-n_{l^*}}\cdot \spr{\pi_{l^*}}
            \\&\leq
            \sum_{i=1}^{l^*}\br{n_i-n_{i-1}}\cdot \frac{\alpha\cdot a^{i+2}}{a-1} + \br{n-n_{l^*}}\cdot \spr{\pi_{l^*}}
            \\&=
            \sum_{i=1}^{l^*}\br{\br{n-n_{i-1}}-\br{n-n_i}}\cdot \frac{\alpha\cdot a^{i+2}}{a-1} + \br{n-n_{l^*}}\cdot \spr{\pi_{l^*}} \leq
            \sum_{i=0}^{l^*}\br{n-n_i}\cdot \frac{\alpha\cdot a^{i+3}}{a-1} = Q.
        \end{align*}
        Here $Q$ denotes the last sum, and the last inequality follows from \eqref{eq:pi}.
        Moreover, we have that:
        \begin{align*}
            &2\cdot\coverageTime\br{\cCopt,\cU}\geq a^{l^*-1}\cdot\br{n-n_{l^*-1}^*}+ \sum_{i=1}^{l^*-1}a^{i-1}\cdot\br{n_i^*-n_{i-1}^*}+\br{n-n_{l^*}^*}\cdot\spr{\cCopt}
            \\&\geq
        a^{l^*-1}\cdot\br{n-n_{l^*-1}^*}+ \sum_{i=1}^{l^*-1}a^{i-1}\cdot\br{\br{n-n_{i-1}^*}-\br{n-n_{i}^*}}+\br{n-n_{l^*}^*}\cdot a^{l^*-1}
            \\&=
        \br{n-n_0^*}+\sum_{i=1}^{l^*-1}\br{a^{i}-a^{i-1}}\cdot\br{n-n_{i}^*}+\br{n-n_{l^*}^*}\cdot a^{l^*-1} \geq
        \br{1-\frac{1}{a}}\cdot\sum_{i=0}^{l^*}a^{i}\cdot \br{n-n_i^*}.
        \end{align*}

        Consider any iteration $i\in \brc{1,\dots,l^*}$ of the inner for loop. Let $\cR_{i-1}=\cU\setminus\cov\br{\bigcup_{j=1}^{i-1}\tau_{l^*}^j}$ be the algorithmic residual at the beginning of iteration $i$. The family $\pref{\cCopt}{\ell_i}$ is precedence-closed, has size $\ell_i\leq a^i\leq a^{i+1}$, and is therefore feasible for the $i$-th $\ProblemBPCSC$ instance. Since it covers $n_i^*$ elements in total and the previously computed solutions cover $n_{i-1}$ elements, it covers at least $n_i^*-n_{i-1}$ elements in $\cR_{i-1}$.
        Thus, $n_i^*-n_{i-1}$ lower bounds the optimum residual coverage in this iteration.
        Hence, by the $\br{\alpha,\beta}$-approximation guarantee, $n_i-n_{i-1}\geq\frac{n_i^*-n_{i-1}}{\beta}$. Rearranging gives $n-n_i\leq\frac{\beta-1}{\beta}\cdot\br{n-n_{i-1}}+\frac{1}{\beta}\cdot\br{n-n_i^*}$.
        Thus,
        \begin{align*}
            &\frac{\br{a-1}\cdot Q}{\alpha}
            =
            \sum_{i=0}^{l^*}a^{i+3}\cdot \br{n-n_i} \leq
            a^3\cdot n + \frac{1}{\beta}\cdot\sum_{i=1}^{l^*}a^{i+3}\cdot \br{n-n_i^*} + \frac{\beta-1}{\beta}\cdot\sum_{i=1}^{l^*}a^{i+3}\cdot \br{n-n_{i-1}}
            \\&\leq
            \frac{2\cdot a^4}{a-1}\cdot\coverageTime\br{\cCopt,\cU}+\frac{\beta-1}{\beta}\cdot\sum_{i=1}^{l^*}a^{i+3}\cdot \br{n-n_{i-1}}
            \\&=
            \frac{2\cdot a^4}{a-1}\cdot\coverageTime\br{\cCopt,\cU}+\frac{\br{\beta-1}\cdot a}{\beta}\cdot\sum_{i=0}^{l^*-1}a^{i+3}\cdot \br{n-n_{i}} \leq
            \frac{2\cdot a^4}{a-1}\cdot\coverageTime\br{\cCopt,\cU}+\frac{\br{\beta-1}\cdot a}{\beta}\cdot\br{a-1}\cdot\frac{Q}{\alpha}.
        \end{align*}
        Rearranging and substituting $a=(3\cdot\beta-1)/(3\cdot\beta-2)$ gives
        \begin{align*}
            \frac{Q}{\alpha\cdot\coverageTime\br{\cCopt,\cU}}
            &\leq \frac{2\cdot a^4}{(a-1)^2\cdot\br{1-\frac{(\beta-1)\cdot a}{\beta}}}
            =\frac{2\cdot\br{\frac{3\cdot\beta-1}{3\cdot\beta-2}}^4}{\br{\frac{3\cdot\beta-1}{3\cdot\beta-2}-1}^2\cdot\br{1-\frac{(\beta-1)\cdot(3\cdot\beta-1)}{\beta\cdot(3\cdot\beta-2)}}} \\
            &\leq \frac{2\cdot(3\cdot\beta-1)^2\cdot a^4}{1-\frac{(\beta-1)\cdot a}{\beta}}
            \leq\frac{2\cdot(3\cdot\beta-1)^2\cdot a^4}{1-\frac{\beta-2/3}{\beta}}
            =3\cdot\beta\cdot(3\cdot\beta-1)^2\cdot a^4
            \leq432\cdot\beta^3.
        \end{align*}
        Here $(a-1)^{-2}=(3\cdot\beta-2)^2\leq(3\cdot\beta-1)^2$, and $1-(\beta-1)\cdot a/\beta=(2\cdot\beta-1)/(\beta\cdot(3\cdot\beta-2))\geq2/(3\cdot\beta)$ for $\beta\geq1$. The final inequality uses $a\leq2$ and $3\cdot\beta-1\leq3\cdot\beta$.
        The lemma follows.
    \end{proof}

    If $\spr{\pi_{l^*}}=m$, then $\pi_{l^*}$ contains every set in $\cS$, and thus covers every element covered by $\cCopt$. The candidate is feasible and its latency is bounded by Lemma~\ref{lem:pi-spread-cost}. Otherwise, let $P_{l^*}$ be the family of sets in $\pi_{l^*}$, let $\cR_{l^*}=\cU\setminus\cov\br{P_{l^*}}$, and let $r=\spr{\cov\br{P_{l^*},\cU}}$.
    \begin{lemma}\label{lem:sigma-coverage}
        We have that $\spr{\cov\br{\sigma_{l^*},\cR_{l^*}}} \geq \frac{\max\brc{0,f\cdot n-r}}{\beta}$ and $\spr{\sigma_{l^*}} = \bigo\br{\alpha}\cdot \spr{\cCopt}$.
    \end{lemma}
    \begin{proof}
        Since $\cCopt$ satisfies $\spr{\cCopt}\leq a^{l^*}$, it is feasible for the final $\ProblemBPCSC$ instance on residual universe $\cR_{l^*}$. It covers at least $\max\brc{0,f\cdot n-r}$ elements of that residual. The approximation guarantee gives the coverage bound, while $\spr{\sigma_{l^*}}\leq\alpha\cdot a^{l^*}\leq\alpha\cdot a\cdot\spr{\cCopt}=\bigo\br{\alpha}\cdot\spr{\cCopt}$ gives the size bound.
    \end{proof}
    Let $\pi_{l^*}^+=\pi_{l^*}\circ\operatorname{ord}\br{\sigma_{l^*}\setminus P_{l^*}}$ denote the sequence obtained by appending only the final solution's new sets.
    \begin{lemma}\label{lem:combined-coverage-cost}
        We have that $\spr{\cov\br{\pi_{l^*}^+,\cU}}\geq \frac{f\cdot n}{\beta}$ and $\coverageTime\br{\pi_{l^*}^+,\cU} = \bigo\br{\alpha\cdot\beta^3}\cdot \coverageTime\br{\cCopt,\cU}$.
    \end{lemma}
    \begin{proof}
        By Lemma~\ref{lem:sigma-coverage}, the prefix and the final solution together cover at least $r+\frac{\max\brc{0,f\cdot n-r}}{\beta}\geq\frac{f\cdot n}{\beta}$ elements. Here the residual coverage from $\sigma_{l^*}$ is disjoint from the prefix coverage by definition of $\cR_{l^*}$.
        For each element $u\in\cU$, let $t_u$ denote the index of the first set in $\pi_{l^*}$ that covers $u$ if $u$ is covered by $\pi_{l^*}$, otherwise set $t_u=\spr{\pi_{l^*}}$.
        Lemma \ref{lem:pi-spread-cost} implies that 
        \[
        \coverageTime\br{\pi_{l^*},\cU}=\sum_{u\in\cU} t_u = \bigo\br{\alpha\cdot\beta^3}\cdot \coverageTime\br{\cCopt,\cU}.
        \]
        Observe, that for each $u\in\cov\br{\pi_{l^*}}$, its coverage time in $\pi_{l^*}^+$ is also $t_u$.
        For each $u\notin\cov\br{\pi_{l^*}}$, we have $t_u=\spr{\pi_{l^*}}$. Since this case has $\spr{\pi_{l^*}}<m$, the padding guarantee gives $\spr{\pi_{l^*}}\geq\alpha\cdot\beta\cdot a^{l^*}$. The appended suffix contains at most $\spr{\sigma_{l^*}}\leq\alpha\cdot a^{l^*}\leq\spr{\pi_{l^*}}/\beta$ new sets. Thus the coverage time of $u$ in $\pi_{l^*}^+$ is at most $(1+1/\beta)\cdot t_u\leq2\cdot t_u$.
        The explicit bound in the proof of Lemma~\ref{lem:pi-spread-cost} therefore gives $\coverageTime\br{\pi_{l^*}^+,\cU}\leq2\cdot\coverageTime\br{\pi_{l^*},\cU}\leq864\cdot\alpha\cdot\beta^3\cdot\coverageTime\br{\cCopt,\cU}=\bigo\br{\alpha\cdot\beta^3}\cdot\coverageTime\br{\cCopt,\cU}$.
    \end{proof}
Since $\log a=\Theta(1/\beta)$, Algorithm~\ref{alg:fPCMSSC} makes $\bigo((1+\beta\log(m+1))^2)$ calls to the budgeted algorithm. Its running time is therefore polynomial whenever $\beta$ is polynomially bounded in the input size. All applications below use constant $\beta$.
By Lemma~\ref{lem:combined-coverage-cost}, the candidate for $l^*$ meets the coverage requirement and has the stated latency bound. Since Algorithm~\ref{alg:fPCMSSC} returns the minimum-latency candidate meeting that coverage requirement, the following theorem follows.
\begin{theorem}\label{thm:BPCSC-to-PCMSSC}
    \setlength{\emergencystretch}{2em}
    If there exists a polynomial-time bicriteria $(\alpha,\beta)$-approximation algorithm for $\ProblemBPCSC$, with $\beta$ polynomially bounded in the input size, then there exists a polynomial-time bicriteria $\br{\bigo\br{\alpha\cdot\beta^3}, \beta}$-approximation algorithm for $\ProblemPCMSSC$.
\end{theorem}
It should be noted that in all cases when we use Theorem~\ref{thm:BPCSC-to-PCMSSC} we will have $\beta=\bigo\br{1}$, thus yielding a $\br{\bigo\br{\alpha}, \bigo\br{1}}$-approximation algorithm for $\ProblemPCMSSC$.

\begin{corollary}\label{cor:PCACDT-general}
There is a deterministic polynomial-time $\bigo\br{m^{1/3}\cdot\log n}$-approximation algorithm for $\ProblemPCACDT$ under general precedence constraints.
\end{corollary}
\begin{proof}
Combine the budgeted guarantee in Theorem~\ref{thm:PCSC-to-BPCSC} with Theorems~\ref{thm:BPCSC-to-PCMSSC} and~\ref{thm:PCMSSC-to-PCACDT}.
\end{proof}

\subsection{Special cases of precedence constraints} \label{subsection:SpecialCases}
In \textsc{Budgeted Maximum Coverage}, the input consists of a universe $\cX$, an indexed family $\cA$ of subsets of $\cX$, costs $c\colon\cA\to\mathbb{R}_{\geq0}$ and a budget $B>0$. The goal is to maximize $\spr{\cov\br{\cA'}}$ over $\cA'\subseteq\cA$ with $\sum_{A\in\cA'}c(A)\leq B$.

\begin{theorem}[Khuller, Moss and Naor \cite{TheBudgetedMaximumCoverageProblem}]\label{thm:budgeted-maximum-coverage-source}
    There is a polynomial-time algorithm for budgeted Maximum Coverage that respects the budget and covers at least a $(1-1/e)$-fraction of the maximum number of elements coverable within that budget.
\end{theorem}

\begin{theorem}\label{thm:BPCSC-inforest}
    \setlength{\emergencystretch}{2em}
    There exist polynomial-time bicriteria $\br{1, \frac{e}{e-1}}$-approximation algorithms for $\ProblemBPCSC$ and $\ProblemPCSC$ when the precedence constraints form an inforest.
\end{theorem}
\begin{proof}
    We reduce $\ProblemBPCSC$ to budgeted Maximum Coverage and apply Theorem~\ref{thm:budgeted-maximum-coverage-source}.

    Given a $\ProblemBPCSC$ instance $(\cU,\cS,\preceq,\budget)$, set $\cX=\cU$ and $B=\budget$. For each $S\in\cS$, create a set $z_S=\cov\br{\closure{S}}$ with cost $c(z_S)=\spr{\closure{S}}$, and let $\cA=(z_S)_{S\in\cS}$ be the indexed family of these sets.
    For any selected family $\cA'\subseteq\cA$, define $\cC_{\cA'}=\bigcup_{S\in\cS\colon z_S\in\cA'}\closure{S}$. This family is precedence-closed and satisfies
    \[
        \cov\br{\cC_{\cA'},\cU}=\cov\br{\cA'}
        \qquad\text{and}\qquad
        \spr{\cC_{\cA'}}\leq\sum_{z_S\in\cA'}c(z_S).
    \]
    In an inforest, intersecting closures are nested: for $S,W\in\cS$, if $\closure{S}\cap\closure{W}\neq\emptyset$, then $S\preceq W$ or $W\preceq S$. Thus, every precedence-closed family $\cC\subseteq\cS$ is the disjoint union of the closures of its maximal members. Selecting the corresponding sets $z_S$ preserves both cost and coverage. The maximum coverage attainable within budget $\budget$ is therefore the same in both instances, which gives the $\ProblemBPCSC$ guarantee.

For $\ProblemPCSC$, return the empty family if $\cU=\emptyset$. Otherwise, run the same construction for every integer budget in $[m]$ and return a smallest family covering at least $(1-1/e)\cdot f\cdot n$ elements. Let $\cCopt$ be an optimal $\ProblemPCSC$ solution. The budget $\spr{\cCopt}$ yields such a family of size at most $\spr{\cCopt}$.
\end{proof}

The preceding algorithm also gives a guarantee for $\ProblemPCMSSC$.
\begin{corollary}\label{cor:BPCSC-inforest-to-PCMSSC}
    \setlength{\emergencystretch}{2em}
    There exists a polynomial-time bicriteria $\br{864\cdot\br{\frac{e}{e-1}}^3, \frac{e}{e-1}}\approx\br{3420.7, \frac{e}{e-1}}$-approximation algorithm for $\ProblemPCMSSC$ when the precedence constraints form an inforest.
\end{corollary}
\begin{proof}
Apply the $\ProblemBPCSC$ algorithm from Theorem~\ref{thm:BPCSC-inforest} with $\alpha=1$ and $\beta=e/(e-1)$ in Algorithm~\ref{alg:fPCMSSC}. The explicit bounds in the proofs of Lemmas~\ref{lem:pi-spread-cost} and~\ref{lem:combined-coverage-cost} give the stated cost ratio, and Lemma~\ref{lem:combined-coverage-cost} gives the coverage guarantee.
\end{proof}

\paraTitle{Steiner problems.}
Let $(V,d)$ denote a symmetric metric with distance function $d\colon V \times V \to \mathbb{R}_{\geq 0}$ satisfying the triangle inequality.
An \emph{$r$-tour} $\tau$ is a walk that starts and ends at $r \in V$. Denote by $\spr{\tau}$ the length of tour $\tau$ with respect to $d$.
Let $\cX$ be a family of \emph{groups}, where $X\subseteq V$ for each $X \in \cX$.
Let $w\colon \cX \to \mathbb{R}_{\geq 0}$ be a weight assignment to groups.
Let $V(\tau)$ be the set of vertices visited by $\tau$. The set of groups \emph{covered} by $\tau$ is $\cov\br{\tau}=\brc{X\in\cX\colon X\cap V(\tau)\neq\emptyset}$.
% For a tour $\tau$ and a group $X \in \cX$, define $t_\tau(X)$ as the length of the shortest prefix of $\tau$ (with respect to $d$) that visits at least one vertex from $X$. If $X \notin \cov\br{\tau}$, we set $t_\tau(X) = \spr{\tau}$.

\begin{problem}[\textsc{Group Steiner Orienteering} (GSO)] \label{problem:GSO}
Given a metric space $(V, d)$, a root vertex $r \in V$, a family of groups $\cX \subseteq 2^V$, a weight function $w\colon \cX \to \mathbb{R}_{\geq 0}$, and a budget $\budget > 0$, find an $r$-tour $\tau$ with $\spr{\tau} \leq \budget$ that maximizes
$\sum_{X \in \cov\br{\tau}} w(X)$.
\end{problem}
The following tree-metric guarantee follows from the algorithm and analysis in Section~5.1 of \cite{ApproxAlgsForOptDTsAndAdapTSPProblems}: for a tree metric, the tree-embedding step is unnecessary, saving a logarithmic factor.
\begin{theorem}[Gupta, Nagarajan and Ravi \cite{ApproxAlgsForOptDTsAndAdapTSPProblems}, Section~5.1]\label{thm:gso-tree-source}
    For a $\ProblemGSO$ instance on a tree metric $(V,d)$ with budget $\budget$, a polynomial-time algorithm finds an $r$-tour of length $\bigo\br{\log\spr{V}}\cdot\budget$ covering groups of total weight at least one quarter of the maximum weight coverable by an $r$-tour of length at most $\budget$.
\end{theorem}

\begin{theorem}\label{thm:BPCSC-outforest}
    \setlength{\emergencystretch}{2em}
    There exist polynomial-time bicriteria $\br{\bigo\br{\log m}, 4}$-approximation algorithms for $\ProblemBPCSC$,  $\ProblemPCSC$ and $\ProblemPCMSSC$ when the precedence constraints form an outforest.
\end{theorem}
\begin{proof}
    We reduce $\ProblemBPCSC$ to $\ProblemGSO$ on tree metrics and apply Theorem~\ref{thm:gso-tree-source}. Let $(\cU,\cS,\preceq,\budget)$ be a $\ProblemBPCSC$ instance. Instances with $m\leq1$ can be solved directly, so assume $m\geq2$.
    
    Create a rooted tree with vertex set $V=\brc{r}\cup\brc{v_S\colon S\in\cS}$, where $r$ is a dummy root. For every minimal $S\in\cS$, connect $r$ to $v_S$ by an edge of length~$1/2$. For every nonminimal $W\in\cS$, let $S\in\cS$ be its unique immediate predecessor, and connect $v_S$ to $v_W$ by an edge of length~$1/2$. Thus, the path from $r$ to $v_W$ visits the representatives of all strict predecessors of $W$. For each $u\in\cU$, let $X_u=\brc{v_S\colon S\in\cS,\ u\in S}$. Set the GSO budget to $\budget$ and define its groups and their weights by
    \[
        \cX=\brc{X_u\colon u\in\cU,\ X_u\neq\emptyset},
        \qquad w(X)=\spr{\brc{u\in\cU\colon X_u=X}}\quad(X\in\cX).
    \]

    Expand each edge of an $r$-tour in the tree metric along its tree path. The resulting walk $\tau$ has the same length and covers every group covered by the original tour. Let $\cC_\tau=\brc{S\in\cS\colon v_S\in V(\tau)}$. The root-to-vertex paths imply that $\cC_\tau$ is precedence-closed. The subtree formed by these paths has $\spr{\cC_\tau}$ edges, one for each visited representative. Since $\tau$ starts and ends at $r$, it traverses each edge in this subtree at least twice. As every edge has length~$1/2$, we have $\spr{\cC_\tau}\leq\spr{\tau}$. The total weight of groups covered by $\tau$ equals $\spr{\cov\br{\cC_\tau,\cU}}$.

    Conversely, for any precedence-closed family $\cC\subseteq\cS$, the union of the root-to-$v_S$ paths for $S\in\cC$ has $\spr{\cC}$ edges. A closed DFS walk traverses each edge twice, so its length is $2\cdot\frac12\cdot\spr{\cC}=\spr{\cC}$ and it covers groups of total weight $\spr{\cov\br{\cC,\cU}}$. Thus the reduction preserves the optimum coverage for each budget. Since $\spr{V}=m+1$, Theorem~\ref{thm:gso-tree-source} gives the $\ProblemBPCSC$ guarantee.

    For $\ProblemPCSC$, return the empty family if $\cU=\emptyset$. Otherwise, run the same construction for every integer budget in $[m]$ and return a smallest family covering at least $f\cdot n/4$ elements. Let $\cCopt$ be an optimal $\ProblemPCSC$ solution. The budget $\spr{\cCopt}$ yields such a family of size $\bigo\br{\log m}\cdot\spr{\cCopt}$. The $\ProblemPCMSSC$ guarantee follows from Theorem~\ref{thm:BPCSC-to-PCMSSC}.
\end{proof}
