# STOC 2027 manuscript review

This record tracks 100 separately scoped revision rounds requested by the authors. Each round has a focused question, source evidence, and an outcome. Changes are circulated to all ten review agents before application. A changed round is compiled, committed, and pushed to `szyfel`. Rounds without warranted changes are recorded without manufacturing edits.

The official submission instructions were checked on 25 October 2026: https://acm-stoc.org/stoc2027/stoc2027-cfp.html. The full-version submission is `main.tex`, and `main_arxiv.tex` is the separate arXiv edition. Submission-facing external tasks such as author consent, conflicts, limits, and the recorded talk are outside this manuscript editing request.
