CHAPTER 1
Imagine trying to identify one hidden object from a list of possibilities. You can ask questions, and each answer eliminates some possibilities. A decision tree records that conversation: every question is a node, each possible answer chooses a branch, and a leaf names the hidden object. For a concrete comparison, take the same twelve hypotheses and consider three alternative tests. One splits them six and six. Another splits them nine and three. A third has three equally likely replies, four hypotheses each. They begin from the same pool; they are not three consecutive steps. The first and third are balanced in their own number of outcomes, while the second is deliberately uneven. In the classical problem, we choose whichever question seems most useful next. Now add a rulebook. Some questions have prerequisites. A test may be informative, but it is not legal until earlier tests have been run. That small change connects adaptive search to precedence-constrained scheduling and covering problems. This article studies how much those prerequisites change the algorithmic picture, for both the longest search path and the average number of tests.

CHAPTER 2
There are two natural costs. The worst-case cost is the length of the longest root-to-leaf path: how many tests might an adversarial target force us to perform? In our eight-outcome example, the leaf depths are two, three, three, three, three, three, four, and four. The maximum is four. The sum is twenty-five, so under a uniform prior the mean depth is twenty-five over eight. The average-case cost in the paper uses the sum; dividing by the number of hypotheses only rescales it. The covering side has a similar pair. A set cover asks for a small family of sets covering a target fraction of the universe. The min-sum version orders the sets and charges each element for the first time it is covered. Precedence applies to both: choosing a set requires choosing every predecessor, and a sequence must place predecessors first. The central question is whether these covering objectives can serve as reliable building blocks for decision trees.

There is a useful way to see the analogy. Imagine each hypothesis as an item waiting to be marked. A test marks a hypothesis once the answer to that test has narrowed the possibilities sufficiently. A sequence of tests therefore induces a sequence of newly covered items. For worst case, we care about how many tests we need before enough items are marked. For average cost, we care about the sum of the times at which the items are marked. The same distinction appears in ordinary set cover and min-sum set cover. The paper develops both sides in parallel, because a reduction that preserves cardinality need not preserve the first-coverage times that drive the average objective.

CHAPTER 3
Without precedence, greedy information gain is a natural instinct. Ask the question that most reduces uncertainty. But with prerequisites, the best question can be locked behind another question that reveals little by itself. In the graph here, two starting tests unlock two middle tests; one middle test unlocks a later test, and that test must be completed before the final merge. There are several legal orders because some prerequisites are independent. Starting with the middle test is illegal. The legal choices are not arbitrary subsets of tests. They form precedence-closed sequences or families. This means that selecting one useful test may force the algorithm to pay for a whole chain of less useful tests first. The paper's response is not to look for one clever greedy score. Instead, it builds a sequence of reductions. Each reduction exposes the combinatorial structure that the next algorithm can handle. The first bridge goes from a decision tree to a covering instance built from tests and hypotheses.

This distinction matters even if the precedence relation is simple to state. A test is available only when every predecessor has already been run on that branch. So a globally attractive test might be unavailable at the root, and different branches can have different histories of completed tests. At the same time, a covering algorithm must return a family closed under all predecessors, not merely a collection that happens to cover the right elements. This is exactly where a naive transfer of the classical greedy arguments breaks: the structure of a chosen solution and the order in which it is executed are part of the optimization problem. The reduction framework lets us package those constraints rather than discard them.

CHAPTER 4
Here is the key geometric idea. In an optimal worst-case decision tree, walk downward from the root until the remaining subtrees are all small, at most half the hypotheses. The tests along the path we just walked form a separator-like sequence, called a sepcover. Its cost is bounded by the optimum decision-tree cost. Now translate tests into sets. A test covers a hypothesis when the reply containing that hypothesis leaves at most three quarters of the original hypothesis pool. If we perform tests that cover a quarter of these separated hypotheses, then any reply that still contains an uncovered hypothesis cannot remain too large. The constants are chosen so this statement survives a bicriteria approximation that may miss part of the target coverage. The constructed cover is not just a metaphor: it is an instance of precedence-constrained set cover, with each test becoming a set and each hypothesis becoming an element.

Let us unpack why the path is useful. The sepcover is chosen at the first point where every component remaining below it is small. Before that point, there is still a branch containing more than half of the hypotheses. The path prefix is therefore a compact certificate that the tree has made substantial progress. Its tests appear in a legal order because they lie on one root-to-node path, and its length cannot exceed the height of the optimal tree. We do not know that optimal path when designing the algorithm. Instead, we use its existence as a benchmark: it proves that the covering instance has a feasible solution whose cost is at most optimum. An approximation for the cover can then find a sequence nearly as good without reconstructing the hidden optimal tree.

The three-quarter threshold leaves slack. A reply that is at most three quarters of the current pool gives a definite shrinkage, while the target cover asks for only a fraction of the hypotheses. These two constants interact with the bicriteria coverage loss. The proof first shows that the union of the separating sets contains all but at most one hypothesis, so there are always enough elements to target. It then extracts a short prefix of the sepcover that reaches the required coverage. Because the prefix respects the original order, it automatically respects precedence. This is why the argument can compare an arbitrary optimal decision tree against a precedence-constrained covering optimum.

CHAPTER 5
The algorithm asks a covering oracle for a precedence-respecting sequence that covers enough of the separated hypotheses. Then it executes those tests, branches on the replies, and recursively solves each smaller decision problem. Why does this recursion stay controlled? The separator argument says the optimal solution pays for a sequence comparable to the cost of the sepcover. The coverage guarantee says each child receives a strictly smaller hypothesis pool. In the analysis, if the covering routine loses a factor beta in coverage, every child has size at most the fraction five beta minus one, divided by five beta, of its parent. So the number of levels is logarithmic. At each level we charge the chosen sequence to a lower bound from the optimal tree. The geometric shrinkage makes those level charges telescope into a logarithmic approximation factor, in addition to the approximation factor of the cover oracle. This proves the reduction from precedence-constrained set cover to worst-case decision trees.

This is a useful example of a proof invariant doing two jobs at once. The cover objective controls the amount we pay to get through the current layer. The coverage threshold controls how much smaller every recursive instance becomes. If either property were missing, recursion could repeat almost the same problem while paying a positive cost at every step. Here, the child-size bound is a fixed fraction below one, so after logarithmically many rounds only a constant number of hypotheses remain. The recurrence charges one layer and then applies itself to smaller subproblems. In the worst-case analysis, we take the largest child cost. In the average-case analysis, we sum the costs of disjoint child hypothesis sets. The two recurrences have different forms, but both inherit the same geometric decrease.

Notice also that this is a reduction theorem, not yet the final approximation ratio. It says: if we can approximately solve the covering problem with cost factor alpha and coverage loss beta, then we can solve the decision-tree problem with a logarithmic overhead depending on beta and the number of hypotheses. The later sections are responsible for building the covering algorithms. Keeping the statements separate clarifies where each logarithm comes from and lets special precedence structures improve the covering step without changing the decision-tree argument.

CHAPTER 6
For the average objective, simply counting selected tests is no longer enough. We must account for when each hypothesis is covered. The min-sum set-cover objective does exactly that: the contribution of an element is the index of its first covering set. The tests along a path in an optimal tree again yield a useful reference sequence. The paper shows that a suitable precedence-respecting prefix of that sequence has min-sum cost bounded by the path-sequence contribution in the tree. The recursive construction can then charge most hypotheses to their first coverage time; the possible leftover hypothesis costs at most the sequence length, which is itself bounded by the total coverage time. This gives the average-case bridge, with a constant factor at each level and logarithmic depth. The difficult step is constructing a good min-sum sequence. For that, the authors introduce budgeted precedence-constrained set cover: under a size budget, cover as many elements as possible. Apply an approximation to this budgeted problem at geometrically increasing budgets. Small early budgets force the algorithm to choose elements that can be covered quickly; later budgets fill in more of the universe. The budgeted problem and the partial-cover problem both reduce to Partial Red-Blue Set Cover, a known approximation problem. That is the technical end point of the algorithmic chain.

The accounting can be visualized by following one hypothesis at a time. Suppose it is first separated by the fourth test in the sequence. Its contribution is four, regardless of how many later tests are selected. If it is never covered by the sequence, we charge the sequence length. Summing these charges over hypotheses gives the min-sum objective. In the decision tree, once a response class is small enough, the algorithm recurses on that class and no longer pays for tests on other branches. A test that covers a hypothesis in the set system guarantees that this hypothesis leaves the current large subproblem. The contribution in the recursive tree is therefore controlled by its coverage time, up to the one possible leftover hypothesis. This is the point where a min-sum cover, rather than a minimum-size cover, matches the average objective naturally.

Why geometrically growing budgets? If we committed to one large budget immediately, an approximation might postpone useful elements until late in the sequence. If we used budgets one, two, three, and so on, the number of calls would be too large and the analysis would not group costs cleanly. Powers of two give logarithmically many scales. Each scale produces a block of sets, and the coverage guarantee from that scale is compared with what an optimal sequence could have covered by the corresponding time. The proof combines the blocks while preserving precedence: each selected block is precedence-closed, and the construction orders its elements so that all required predecessors have already appeared. The result is an approximation for partial min-sum covering, which is exactly the fractional target needed by the recursive decision-tree algorithm.

CHAPTER 7
The resulting general guarantees have order m to the one-third, up to logarithmic factors, for the covering problems and for both decision-tree objectives. The article's explicit bounds include powers of log m and log n from the reductions and recursion. The paper also studies two sparse shapes of precedence. In an inforest, each node has at most one successor. The budgeted covering problem can be encoded as Maximum Coverage, giving logarithmic approximation guarantees for the decision-tree variants. In an outforest, each node has at most one predecessor. Here a sequence of sets traces a walk through the precedence structure, making the relation to graph exploration more visible. A reduction to Group Steiner Orienteering on trees gives a logarithmic bicriteria approximation for the budgeted cover and, consequently, a squared-logarithmic approximation for both decision-tree objectives. These are not merely faster cases of the same proof: the shape of the precedence graph changes which familiar optimization problem can be used.

For arbitrary precedence, the approximation chain passes through Partial Red-Blue Set Cover, using the result available from the 2023 approximation literature. The cover-size problem reduces directly. The min-sum problem needs the intermediate budgeted problem because its objective depends on order, not only on the final selected family. That distinction explains why the average-case guarantee carries a more involved construction even though the high-level decision-tree reduction looks parallel. The symbols hidden in the tilde notation are logarithmic factors, so the precise general bounds in the article are of order m to the one-third times log to the four-thirds of m and log squared of n for decision trees. For the covering objectives, the corresponding bounds have one fewer log n factor. The special forest bounds replace the dependence on m by polylogarithmic dependence on n.

These guarantees also illustrate why it is useful to keep the set-covering problems as independent contributions. A better algorithm for Partial Red-Blue Set Cover, or a structural improvement for one of the forest variants, can flow through the reduction diagram into a better decision-tree algorithm. Conversely, any lower bound for a covering problem can often flow back to a decision-tree problem. The reductions create a modular interface between active learning and combinatorial covering.

CHAPTER 8
The lower bounds show that the difficulty is real. One route starts from Planted Dense Subgraph. The graph on screen is one reproducible random draw from the model: the six highlighted vertices were selected randomly, and every edge, including each edge inside that set, was sampled independently at its specified probability. The highlighted vertices are not forced to form a clique. A graph is encoded into a precedence-constrained covering instance. The construction used in earlier work represented edges; this article sharpens it by representing larger cliques and by improving the probabilistic analysis. In the planted case, there is a denser hidden structure and the covering instance has a relatively cheap solution. In the random case, a comparably cheap cover would reveal a dense structure that should not exist, so any feasible approximation must pay more. The improved exponents rule out bicriteria cost factors of order n to the one-half minus epsilon and m to the one-quarter minus epsilon, under the Planted Dense Subgraph Conjecture, for the studied objectives. The bicriteria statement also tracks the coverage-loss parameter. These bounds hold for every fixed target coverage fraction, including shallow precedence DAGs. This reduction transfers the hardness from graph structure into the cost of choosing a precedence-closed cover.

The clique parameter is doing real work here. A single edge gives a relatively weak signal when we compare a planted dense region against a random graph. Encoding larger cliques amplifies the gap between the two distributions. But larger structures also create more dependencies among the encoded objects, so the soundness calculation must control how many such objects can appear in the random case. The article sharpens the probabilistic estimate and then translates the graph gap into covering cost. It proves separate bounds in terms of the universe size n and the number of sets m, because the reduction changes those quantities at different rates. The result strengthens the earlier exponents from one-sixth and one-twelfth to one-half and one-quarter, respectively. This is conditional average-case hardness: the assumption concerns distinguishing a planted dense graph from a random one, rather than a standard worst-case complexity assumption.

The reduction also respects the objectives we care about. In the min-sum variant, a cheap sequence would cover enough elements early, so the same structural gap forces a high cumulative coverage time. The construction works for a fixed partial coverage target, which matters because the recursive decision-tree reductions ask for a constant fraction rather than necessarily a full cover. Finally, the precedence DAG can have height two. So the difficulty does not require a long chain of prerequisites; even shallow dependencies can make the approximation problem hard.

CHAPTER 9
The second hardness route begins with Label Cover, where one must assign labels to vertices so that many edge constraints are satisfied. The reduction creates a universe whose elements are short walks in local expanders, represented as stars. Choosing a label is represented by selecting a bundle of predecessor sets. A witness set covers a star only after the bundles for all the labels required along its constraints have been chosen. In a perfectly satisfiable instance, choose the bundles from a satisfying labeling and then select all the witnesses: the cover is cheap. In a low-soundness instance, a cheap cover may contain many different labels at each vertex. The analysis calls a vertex heavy if too many of its label bundles are selected. Since the solution has a limited budget, there cannot be too much total heavy weight. Thus many covered stars touch only light vertices. For a light vertex there are few selected labels, so choosing one of them at random recovers a satisfying label with nontrivial probability. Expander walks make it unlikely that too many stars are covered unless this random labeling satisfies too many constraints. That would contradict low soundness. Consequently, even partial covers and min-sum sequences become expensive. The construction has height-two precedence and sets of size at most one. By choosing parameters from known Label Cover hardness, the paper rules out polylogarithmic approximations unless P equals NP, and stronger subpolynomial guarantees under ETH; the Projection Games Conjecture yields polynomial-factor hardness. This is the most technical part of the paper, and the heavy/light argument is its central intuition.

The expander is important because the walk positions are correlated; they are not independent samples of constraints. A rapidly mixing walk still has a concentration estimate strong enough for the soundness proof. For one fixed label, the probability that all visited positions lie among its compatible constraints is bounded in terms of the fraction of compatible positions and the expander's second eigenvalue. A union bound handles the small number of labels at a light vertex. This gives a way to turn a large collection of covered walk-stars into a labeling that satisfies many original constraints. The argument runs in reverse for soundness: if every labeling satisfies only a small fraction of constraints, then any cover meeting a specified fraction of stars must select many sets.

The bundle construction handles the fact that a cover can select several labels for one vertex, unlike a genuine Label Cover assignment, which chooses only one. Each label bundle has weight proportional to how often that vertex occurs in the stars. Therefore, if the total selected-set budget is small, only a small total weight can belong to vertices with too many complete bundles. Remove the stars that touch those heavy vertices. On the remaining stars every vertex is light, and random rounding can choose one of its selected labels with probability at least the reciprocal of the lightness threshold. This is a clean heavy-light template: budget controls the heavy mass, while random assignment extracts a valid source solution from the light mass.

The parameter t is the number of constraint positions in each star. Increasing t changes both the soundness exponent and the size of the expander-walk universe. Instantiating the construction with different Label Cover promises gives different hardness regimes. Strong parallel repetition yields the ETH bound against bicriteria factors of the form two to a subpower of the logarithm. A stronger projection-games assumption yields polynomial-factor bicriteria hardness. The precise statements track both cost inflation and coverage loss; the intuitive message is that allowing the algorithm to miss some target elements does not erase the gap, because the soundness argument applies to every fixed covered fraction.

CHAPTER 10
The full picture is a pair of reduction ladders. For algorithms, a separator in the optimal decision tree becomes a partial cover; a cover creates a batch of tests that shrinks the remaining hypothesis set; recursion finishes the identification. For average cost, first-coverage times preserve the right accounting, and a budgeted covering problem produces the sequence. For hardness, graph structure and Label Cover assignments are encoded into small precedence-constrained covers, showing that the covering problems retain the hardness of their sources. The framework therefore links adaptive identification, set covering, and precedence-constrained exploration. Several questions remain. Could a local greedy rule based on information gain and closure achieve a good approximation? Can the average-case reduction work with nonuniform prior probabilities? And can the outforest hardness be transferred to average-case decision trees in the uniform setting? These questions mark where the current techniques stop. The main lesson is that precedence makes a useful question costly through its prerequisites, but reductions let us reason about that cost one layer at a time.
